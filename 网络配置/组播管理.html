组播管理使用说明

1 概述

组播管理是 iKuai OS V4 网络配置中的多媒体业务转发与代理模块，主要用于处理组播流量接入、IPTV 透传以及 UDP 组播转 HTTP 访问等典型场景。通过该模块，管理员可以在同一页面中完成 IGMP 代理、IPTV 透传与 UDPXY 代理服务的配置，以满足电视直播、组播视频分发、多终端媒体接入等业务需求。

在日常运维场景中，组播管理通常用于以下方面：

  • 组播流量转发：通过 IGMP 代理实现组播流量在上联和下联网络间的转发；
  • IPTV 业务接入：通过 IPTV 透传将运营商 IPTV 业务引入内网指定接口；
  • 终端兼容扩展：通过 UDPXY 将 UDP 组播流转换为可被更多终端访问的代理流；
  • 多业务分发管理：针对不同业务接口、VLAN 与代理规则进行统一管理；
  • 减少网络资源浪费：在一对多媒体分发场景中降低重复发送带来的带宽占用。

组播管理模块主要包含以下三个部分：

  1. IGMP 代理：用于管理组播成员关系和组播转发路径；
  2. IPTV 透传：用于将 IPTV 业务流量按接口或 VLAN 方式透传至内网；
  3. UDPXY 设置：用于创建 UDPXY 代理规则，将组播访问能力扩展给更多终端。

2 参数解释与操作导航

2.1 访问路径

  1. 登录 iKuai OS V4 Web 管理后台。
  2. 在左侧导航栏中选择【网络配置】。
  3. 点击【组播管理】，进入组播管理页面。

2.2 界面布局

组播管理页面采用纵向模块化布局，主要包括【IGMP代理】、【IPTV透传】和【UDPXY设置】三个功能区域。管理员可按业务需求分别配置，也可组合使用，以满足不同组播业务场景。

2.3 IGMP代理

IGMP 代理用于管理组播流量的上下联转发关系，是组播业务接入的基础功能。通过该模块，可指定组播流量的上联入口和下联出口，并选择对应的 IGMP 协议版本。

IGMP代理

参数解释表

参数名称详细说明
IGMP代理用于控制是否启用 IGMP 代理功能。
IGMP协议版本用于选择当前组播代理使用的 IGMP 协议版本。
上联端口用于指定组播流量进入设备的上联接口。
下联端口用于指定组播流量转发到内网的下联接口。

功能按钮说明

  • 保存：用于保存当前 IGMP 代理配置。

2.4 IPTV透传

IPTV 透传用于将 IPTV 业务流量从指定上联接口透传到内网接口或 VLAN 中，适用于运营商 IPTV 业务接入、机顶盒部署和多端口 IPTV 分发等场景。

IPTV透传

参数解释表

参数名称详细说明
IPTV透传用于控制是否启用 IPTV 透传功能。
透传模式用于选择 IPTV 业务的透传方式。
输入口用于指定 IPTV 业务流量进入设备的接口。
业务VLAN ID*用于指定 IPTV 业务所属的 VLAN 标识。
输出口用于指定 IPTV 业务流量透传到内网的接口。
内网VLAN ID*用于指定内网侧承载 IPTV 业务的 VLAN 标识。

功能按钮说明

  • 保存：用于保存当前 IPTV 透传配置。
  • 帮助：用于查看 IPTV 透传相关帮助说明。

2.5 UDPXY设置

UDPXY 设置用于管理 UDP 组播代理规则。通过该模块，可将组播源流量映射为代理访问服务，便于更多终端通过统一方式访问组播内容。

2.5.1 UDPXY设置列表

UDPXY设置

参数解释表

参数名称详细说明
名称显示当前 UDPXY 代理规则的名称，用于区分不同代理服务。
信号源接口显示当前 UDPXY 规则绑定的组播信号源接口。
服务端口显示当前 UDPXY 规则对外提供代理访问的服务端口。
订阅周期显示当前 UDPXY 规则的订阅刷新周期。
外网访问显示当前 UDPXY 代理服务是否允许外网访问。
操作提供对当前 UDPXY 规则进行维护的操作入口。

功能按钮说明

  • 添加：用于新建 UDPXY 代理规则。
  • 导入：用于批量导入 UDPXY 配置规则。
  • 导出：用于导出当前 UDPXY 配置规则。
  • 帮助：用于查看 UDPXY 相关帮助说明。
  • 操作列按钮：用于对已有规则执行编辑、启用或停用、删除等维护操作。

2.5.2 新增UDPXY规则

点击 UDPXY 设置区域中的【添加】按钮后，可打开规则配置界面。该界面用于定义新的 UDPXY 代理规则，是部署组播代理访问服务的核心入口。

新增UDPXY规则

参数解释表

参数名称详细说明
名称*用于填写 UDPXY 代理规则名称，便于后续识别和管理。
信号源接口用于指定当前代理规则所使用的组播信号源接口。
服务端口用于设置 UDPXY 代理服务监听端口。
订阅周期用于设置代理规则的订阅周期或刷新间隔。
外网访问用于控制当前 UDPXY 代理服务是否允许外网访问。
注：带 * 的项为必填项。

功能按钮说明

  • 保存：用于保存当前 UDPXY 代理规则。
  • 取消：用于放弃当前修改并关闭配置界面。

3 核心运维与操作流程

3.1 配置IGMP代理

操作步骤

  1. 进入【网络配置】→【组播管理】页面。
  2. 在【IGMP代理】区域中启用组播代理功能。
  3. 选择合适的 IGMP 协议版本。
  4. 配置上联端口和下联端口。
  5. 点击【保存】完成配置。

验证方法

  • 确认内网终端能够正常发起组播订阅；
  • 检查组播业务是否可从上联接口正常转发到下联网络。

3.2 配置IPTV透传

操作步骤

  1. 在【IPTV透传】区域中启用 IPTV 透传功能。
  2. 选择透传模式。
  3. 配置输入口和输出口。
  4. 根据业务要求填写业务 VLAN ID 和内网 VLAN ID。
  5. 点击【保存】完成配置。

验证方法

  • 检查 IPTV 终端是否能够正常接收直播节目；
  • 确认输入接口、输出接口及 VLAN 配置与实际业务规划一致。

3.3 配置UDPXY代理规则

操作步骤

  1. 在【UDPXY设置】区域点击【添加】。
  2. 填写规则名称。
  3. 选择信号源接口。
  4. 设置服务端口、订阅周期和外网访问策略。
  5. 点击【保存】完成规则创建。
  6. 返回 UDPXY 列表确认规则已生成并处于预期状态。

应用建议

  • 服务端口应避免与现有业务端口冲突；
  • 外网访问建议按业务需要谨慎开启；
  • 规则名称建议体现业务来源、用途或服务对象，便于后续维护。

4 常见问题与故障排除

常见问题可能原因处理建议
IGMP代理启用后组播业务仍无法转发上联端口或下联端口配置错误；协议版本不匹配重新核对接口配置及 IGMP 协议版本设置。
IPTV透传后终端无法正常观看输入口、输出口或 VLAN ID 配置不一致检查业务接口和 VLAN 参数是否与实际网络规划一致。
UDPXY规则创建后无法访问服务端口冲突、信号源接口错误或访问策略限制检查端口占用情况、信号源接口绑定和外网访问策略。
组播业务时断时续接口连通性异常或订阅周期配置不合理检查接口状态，并结合业务情况调整相关参数。
配置保存后未达到预期效果参数填写不完整或业务链路存在其他限制逐项核对配置内容，并结合业务链路检查上下游网络环境。
