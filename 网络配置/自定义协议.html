自定义协议使用说明

1 概述

自定义协议是 iKuai OS V4 网络配置中的协议对象管理模块，用于定义系统内置协议之外的业务识别条件，并为后续的分流策略、访问控制、行为控制等功能提供可复用的协议匹配对象。通过该模块，管理员可以根据业务流量特征，自定义网络协议对象或构建高级协议组合，从而提升策略配置的精细度与复用性。

在实际运维场景中，自定义协议主要用于以下方面：

  • 扩展协议识别范围：为企业内部私有业务、专用系统或特殊端口流量创建可识别的协议对象；
  • 支撑策略复用：将一次定义的协议对象复用到分流、限速、控制和审计等多个功能模块中；
  • 提升策略表达能力：通过源地址、目的地址、协议类型、源端口、目的端口等条件精确描述业务流量；
  • 构建协议组合：通过高级自定义协议将多个基础协议对象进行逻辑组合，便于统一管理复杂业务场景；
  • 降低运维复杂度：将复杂流量特征抽象为易读的协议名称，便于后续维护、排障和交接。

自定义协议模块通常分为两类：

  1. 自定义协议：用于创建基础协议对象，按地址、协议和端口等条件进行匹配；
  2. 高级自定义协议：用于在已有基础协议对象之上进行组合，形成更高层级的协议对象。

2 参数解释与操作导航

2.1 访问路径

  1. 登录 iKuai OS V4 Web 管理后台。
  2. 在左侧导航栏中选择【网络配置】。
  3. 点击【自定义协议】，进入自定义协议管理页面。

2.2 自定义协议

自定义协议列表用于展示当前已创建的基础协议对象，并提供新增、导入、导出、查询和维护入口。管理员可在该页面查看协议对象的基本属性，并对现有配置进行统一管理。

协议特征说明

  • Protocol：用于定义协议类型。

3 核心运维与操作流程

3.1 创建基础自定义协议

操作步骤

  1. 进入【网络配置】→【自定义协议】页面。
  2. 在【自定义协议】标签页中点击【添加】。
  3. 选择协议分类，并填写协议名称。
  4. 根据业务需求配置源地址、目的地址、协议、源端口和目的端口。
  5. 如需补充说明，可填写备注。
  6. 点击【保存】，完成基础自定义协议创建。

应用建议

  • 对业务名称统一命名，便于后续搜索和引用；
  • 地址条件和端口条件应尽量与业务实际特征保持一致，避免匹配范围过大；
  • 对长期使用的协议对象建议填写备注，便于运维交接。

3.2 批量导入协议对象

操作步骤

  1. 进入【自定义协议】标签页。
  2. 点击【导入】或批量导入入口。
  3. 下载系统模板并按模板格式整理协议数据。
  4. 上传整理完成的导入文件。
  5. 执行导入操作并检查导入结果。
  6. 返回列表页确认导入的协议对象是否完整生成。

验证方法

  • 检查导入后的协议名称、地址条件、协议类型和端口条件是否正确；
  • 确认异常记录已被修正后再正式使用。

3.3 创建高级自定义协议

操作步骤

  1. 切换到【高级自定义协议】标签页。
  2. 点击【添加】按钮，进入高级自定义协议配置界面。
  3. 填写协议名称。
  4. 选择一个或多个基础协议对象作为包含协议。
  5. 设置协议间的逻辑关系。
  6. 按需填写描述，并决定是否立即启用。
  7. 点击【保存】，完成高级自定义协议创建。

应用建议

  • 建议先创建并验证基础协议对象，再进行高级组合；
  • 对协议组合关系较复杂的场景，建议优先使用简明命名和清晰描述，便于后续维护。

3.4 在策略中引用自定义协议

自定义协议对象创建完成后，可在分流策略、行为控制、访问控制等需要协议对象的功能中直接引用。

推荐流程

  1. 先完成基础协议或高级协议对象的创建。
  2. 在目标策略模块中选择相应协议对象。
  3. 保存策略并观察业务流量是否按预期匹配。
  4. 如匹配结果异常，可返回自定义协议模块调整地址、协议或端口条件。

4 常见问题与故障排除

常见问题可能原因处理建议
创建协议后策略未生效协议名称已被引用错误、地址或端口条件设置不准确检查协议对象的地址范围、协议类型和端口配置，并确认策略中引用的是正确对象。
业务流量未被识别协议匹配条件过窄或实际业务端口与配置不一致对照业务实际使用的地址、协议类型和端口重新核对配置。
协议匹配范围过大地址或端口条件设置过宽缩小地址对象范围，使用更精确的端口条件或协议类型。
批量导入失败导入模板格式不符合系统要求重新下载模板并按要求整理字段内容后再次导入。
高级协议组合效果不符合预期包含协议选择错误或逻辑关系设置不当重新检查包含协议对象及逻辑关系设置，必要时拆分为多个协议对象分别验证。
