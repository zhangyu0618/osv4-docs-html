终端限速使用说明

1 概述

终端限速是 iKuai OS V4 系统中的带宽管控功能模块，用于对终端设备的网络带宽进行精细化限制和管理。当多终端共享带宽时，终端限速能够有效防止个别设备（如 P2P 下载、大文件传输）占用过多带宽，保障关键业务和重要终端的带宽需求。

终端限速模块支持基于 IP 地址 和 MAC 地址 两种维度的限速策略，可根据终端类型灵活选择。IP 限速适用于固定 IP 地址的设备（如办公电脑、服务器），MAC 限速适用于动态获取 IP 的设备（如移动终端、无线设备），确保限速策略始终对目标终端生效。

在日常运维场景中，终端限速通常用于以下方面：

  • 带宽公平分配：防止个别终端过度占用带宽，保障多终端并发业务的体验；
  • 关键业务保障：为服务器、视频会议终端等关键设备分配专属带宽，确保核心业务稳定运行；
  • 异常流量管控：对高带宽消耗的终端设备进行限速，防止带宽被滥用；
  • 精细化带宽管理：结合协议、端口、生效时间等条件，实现多维度的带宽管控。

终端限速模块主要包含以下核心功能：

  • IP 限速：基于 IP 地址、IP 网段或批量 IP 地址的带宽限制策略；
  • MAC 限速：基于 MAC 地址、批量 MAC 地址或 MAC 组的带宽限制策略；
  • 双标签页布局：通过 IP 限速和 MAC 限速两个标签页在同一界面切换管理；
  • 批量操作：支持策略的导入、导出、批量启用/停用/删除。

2 参数解释与操作导航

2.1 访问路径

  1. 登录 iKuai OS V4 Web 管理后台。
  2. 在左侧导航栏中选择【网络配置】，展开二级菜单。
  3. 选择【终端限速】，进入终端限速管理页面。

如下图所示：

访问终端限速页面

2.2 IP 限速

IP 限速标签页用于管理基于 IP 地址的终端限速策略。列表展示所有已配置的 IP 限速策略，包含策略名称、目标地址、带宽限制、生效时间等关键信息。

2.2.1 IP限速列表

IP 限速列表如下图所示：

IP 限速列表

参数解释表

参数名称详细说明
名称限速策略的自定义名称，用于快速识别策略归属。
线路限速策略绑定的物理或逻辑接口（如 wan1、lan1），策略将应用于该接口的进出流量。
内网地址目标终端的 IP 地址或网段。支持单 IP（如 192.168.1.10）、CIDR 网段（如 192.168.1.0/24）或批量 IP。

下行限速该策略的最大下行带宽限制，单位为 KB/s。

备注该限速策略的备注信息，用于说明策略用途。
操作对每条限速策略进行管理操作，包含 编辑、启用/停用 和 删除 三个按钮：<br>- 编辑：修改策略参数。<br>- 启用：当前策略为停用状态时显示，点击后启用该策略。<br>- 停用：当前策略为启用状态时显示，点击后停用该策略（保留配置）。<br>- 删除：永久删除该限速策略。

功能按钮说明

  • 添加：创建新的 IP 限速或 MAC 限速策略。
  • 导入：批量导入限速策略（支持 CSV 格式，需包含名称、线路、内网地址、上下行限速等核心字段）。
  • 导出：导出当前所有限速策略，用于备份或跨设备迁移。
  • 帮助：查看终端限速功能的帮助说明。

  • 取消：放弃当前配置内容，退出当前设置界面。

MAC 限速标签页用于管理基于 MAC 地址的终端限速策略。通过对特定 MAC 地址或 MAC 组设置带宽限制，确保设备 IP 变化时限速策略持续生效。

3 核心运维与操作流程

3.1 创建 IP 限速策略

操作步骤

  1. 进入【网络配置】→【终端限速】页面，确保当前为【IP限速】标签页。
  2. 点击 添加 按钮，打开新增限速弹窗。
  3. 配置以下参数：
  • 名称：输入限速策略的名称（如"办公电脑限速"）。
  • 线路：选择限速策略绑定的线路（如 wan1）。
  • 内网地址：输入需要限速的终端 IP 地址或网段。
  • 上行限速/下行限速：设置该终端的上下行带宽上限（单位为 KB/s）。
  • 生效时间：选择限速规则的生效时间计划。
  1. 点击 确定 保存策略。

参数规划建议

  • 带宽单位注意转换：1Mbps ≈ 128KB/s。
  • 建议先小带宽测试验证，确认策略生效后再调整至目标值。

验证方法

  • IP 限速列表中显示新添加的策略。
  • 策略状态显示为已启用。
  • 在目标终端进行测速，验证限速效果。

3.2 创建 MAC 限速策略

操作步骤

  1. 进入【网络配置】→【终端限速】页面，切换至【MAC限速】标签页。
  2. 点击 添加 按钮，打开新增限速弹窗。
  3. 配置以下参数：
  • 名称：输入限速策略的名称（如"会议室设备限速"）。
  • 协议栈：选择 IP 协议版本（IPv4/IPv6/双栈）。
  • 线路：选择限速策略绑定的线路。
  • MAC 地址：输入需要限速的终端 MAC 地址。
  • 上行限速/下行限速：设置该终端的上下行带宽上限。
  • 生效时间：选择限速规则的生效时间计划。
  1. 点击 确定 保存策略。

验证方法

  • MAC 限速列表中显示新添加的策略。
  • 策略状态显示为已启用。
  • 在目标设备进行网络测试，验证限速效果。

3.3 导入与导出策略

终端限速支持批量导入和导出策略，便于策略备份和跨设备迁移。

导出操作步骤

  1. 在 IP 限速或 MAC 限速标签页中，点击 导出 按钮。
  2. 系统下载包含当前所有策略配置的 CSV 文件。

导入操作步骤

  1. 在 IP 限速或 MAC 限速标签页中，点击 导入 按钮。
  2. 选择符合格式要求的 CSV 文件。
  3. 系统自动解析并批量创建限速策略。

4 常见问题与故障排除

问题现象排查步骤
限速策略不生效已配置并启用限速策略，但终端带宽未受限制① 确认策略已启用（状态显示为"启用"而非"停用"）；<br>② 检查 IP 地址或 MAC 地址是否正确匹配目标终端；<br>③ 检查协议、端口参数是否限制过严导致流量未匹配；<br>④ 检查生效时间是否包含当前时间。
带宽限制不准确配置了限速值，但实际带宽与配置不符① 检查带宽单位（KB/s）是否正确换算（1Mbps = 128KB/s）；<br>② 使用专业测速工具测试，避免终端缓存影响结果；<br>③ 检查是否存在其他限速策略造成叠加或冲突。
MAC 限速不生效为目标 MAC 配置了限速，但设备带宽未受限① 确认 MAC 地址格式正确（格式如 58:CE:84:38:74:BF）；<br>② 确认协议栈选择（IPv4/IPv6/双栈）与设备网络类型一致；<br>③ 确认限速线路与设备实际接入线路一致。
策略冲突多个限速策略针对同一终端，限速效果不符合预期① 检查是否存在同一终端的 IP 限速和 MAC 限速同时生效；<br>② 检查各策略的优先级（数值越小优先级越高），高优先级策略优先生效；<br>③ 移除或调整冲突策略。
