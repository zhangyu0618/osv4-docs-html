用户日志使用说明

1. 概述

用户日志模块是网络设备进行安全审计与行为追溯的核心功能组件，位于【日志中心】之下。它专注于记录与用户、终端直接相关的网络活动，而非系统底层事件，为管理员提供了洞察网络访问、认证安全和终端连接状态的专属窗口。

该模块采用清晰的标签页布局，集成了【认证】、【ARP】 和【无线终端】 三大日志维度：

  • 认证日志：记录所有用户的登录、退出、认证失败等行为，是排查VPN接入问题、审计账户安全的第一手资料。
  • ARP日志：监控局域网内的ARP协议活动，主动告警ARP欺骗、IP冲突等二层网络攻击，是维护网络基础通信稳定的关键。
  • 无线终端日志：追踪每一个Wi-Fi设备的接入、断开、漫游全过程，并记录信号强度、接入点等详细信息，是优化无线网络、定位连接故障的利器。

通过统一的“列表展示 + 组合筛选 + 数据导出”管理范式，本模块旨在将海量的原始日志转化为可检索、可分析、可审计的有效信息，帮助管理员高效完成安全事件回溯、网络故障定位与合规性检查等核心运维任务。

2 参数解释与操作导航

2.1 界面布局

依次点击【日志中心】>【用户日志】，进入用户日志页面。

用户日志页面采用多标签页布局，主要包含【认证】、【ARP】和【无线终端】三个功能模块。三个模块均采用“日志列表 + 筛选日期 + 导出/清空 + 帮助”的管理方式，用于查看对应场景下的日志记录，并支持通过显示选项对筛选器或列进行展示控制。

2.2 认证

认证页面为用户认证行为的日志查看控制台，支持按时间范围查看认证记录，并对当前日志执行导出、清空等操作；列表中展示时间、用户名、认证 IP、认证类型、IP/MAC、事件、接口及日志详情等关键信息，便于管理员快速定位某一用户或某一时间段内的认证行为。

功能按钮说明

  • 搜索框：输入关键词（如用户名、IP）快速筛选日志；
  • 筛选日期：选择时间范围，筛选指定时间段内的认证日志；
  • 导出：将当前日志列表导出为文件（如CSV），便于离线分析；
  • 清空：清空筛选条件或临时数据（需谨慎操作，避免误删日志）；
  • 显示选项：点击!12 显示选项图标图标，打开显示选项设置窗口；
  • 筛选：当鼠标指向日志列表的列标题时，会出现!10 筛选图标图标；点击该图标可弹出的筛选菜单，进而对该列的内容进行筛选操作。

2.2.2 显示选项（筛选器）

点击!12 显示选项图标图标，打开显示选项设置窗口，显示选项包含“筛选器”和“列”两个标签。在筛选器标签中，支持通过“用户名”、“认证IP”、“认证类型”、“IP/MAC”、“事件”、“接口”的组合筛选，精准定位目标日志（如快速查找某用户的VPN登录日志)。

认证显示选项（筛选器）页面如下图所示：

功能按钮说明

  • 选择：打开对应筛选界面，设置精确/模糊匹配条件（如按IP网段、认证类型下拉选择）；
  • 还原列：重置筛选条件选择状态，恢复默认筛选字段显示。

2.2.3 显示选项（列）

显示选项的列标签中支持自定义日志列表的列显示/隐藏（如仅显示“时间、用户名、事件”核心列，或显示全部字段），满足不同审计场景的可视化需求。

认证显示选项（列）页面如下图所示：

显示选项（列）页面

功能按钮说明

  • 全选：勾选后显示日志列表的所有列，取消则隐藏所有列；
  • 复选框：单独控制对应列的显示/隐藏（勾选=显示，取消=隐藏）；
  • 还原列：恢复列的默认显示状态（如默认显示所有列或特定核心列）。

2.3 ARP

ARP日志页面用于记录、审计与分析网络中的ARP（地址解析协议）相关事件，展示ARP事件的触发时间、事件详情（含IP/MAC地址映射、接入接口、攻击类型等核心信息）；支持通过搜索、时间筛选、导出、清空等功能管理日志，帮助管理员快速定位ARP欺骗、IP/MAC冲突、ARP请求异常等网络安全问题，保障网络地址解析的稳定性与安全性。

功能按钮说明

  • 搜索框：输入关键词（如IP、MAC、接口名），快速筛选包含关键词的ARP日志，缩小排查范围；
  • 筛选日期：选择时间范围（如近1小时、自定义日期区间），筛选指定时段内的ARP日志，聚焦特定周期内的事件；
  • 导出：将当前ARP日志列表（含筛选后数据）导出为文件（如CSV/Excel），便于离线分析、存档或上报；
  • 清空：清空当前日志列表的筛选条件或临时数据（注意：若未筛选，可能清空全部ARP日志，需谨慎操作）。
  • 显示选项：点击!12 显示选项图标图标，打开显示选项设置窗口；
  • 筛选：当鼠标指向日志列表的列标题时，会出现!10 筛选图标图标；点击该图标可弹出的筛选菜单，进而对该列的内容进行筛选操作。

2.4 无线终端

无线终端页面用于监控与管理接入无线网络的终端设备，展示终端的接入时间、设备标识（MAC/名称）、接入的AP、无线网络（SSID）、信号强度、认证事件及操作结果等信息；支持通过搜索、时间筛选、导出、清空等功能，帮助管理员追踪终端接入状态、排查无线连接故障（如信号弱、认证失败）、审计无线安全事件（如非法终端接入、异常断开）。

3. 核心运维与操作流程

本章节详细说明使用用户日志模块进行日常审计与排查的标准操作流程。

3.1 查询与筛选特定日志

此操作用于从大量日志中快速定位关注的事件。

  1. 选择日志类型：在用户日志页面，根据目标点击顶部的 【认证】、【ARP】 或 【无线终端】 标签，切换到对应日志列表。
  2. 进行时间筛选：点击列表右上角的 「筛选日期」，选择预设的时间范围（如“今天”、“最近1小时”）或自定义起止日期，缩小查询范围。
  3. 使用关键词搜索：在顶部的 「搜索框」 中输入关键词（如用户名ovpn_test_0424、IP地址192.168.33.118、MAC地址f6：40：f7：c2：26：63），系统将实时过滤出包含该关键词的日志行。
  4. 启用高级筛选器（以认证日志为例）：
  • 点击列标题（如“用户名”）右侧的 筛选图标，或在页面点击 「显示选项」 并选择 「筛选器」 标签。
  • 在弹出的窗口中，可以组合多个条件进行筛选，例如：
  • 设置 「认证类型」 为 OpenVPN。
  • 设置 「事件」 为 退出登录。
  • 在 「用户名」 栏位进行模糊匹配。
  • 点击 「保存」，列表将只显示同时满足这些条件的日志。

验证方法：观察日志列表，确认显示的结果条数减少，且每条记录都符合所设置的筛选条件。

3.2 自定义列表视图

此操作用于调整日志列表显示的字段，聚焦关键信息。

  1. 进入列设置：在日志列表页面，点击 「显示选项」，然后选择 「列」 标签。
  2. 勾选显示字段：在列表中，通过复选框选择或取消选择需要显示的列。例如，在审计认证日志时，可以只勾选 「时间」、「用户名」、「事件」 和 「日志详情」，隐藏其他列以使界面更简洁。
  3. 应用设置：操作后，页面会自动刷新，日志列表将按新的列设置进行展示。

验证方法：返回日志列表，确认显示的列标题与刚才勾选的选项完全一致。

3.3 导出与归档日志

此操作用于将日志数据导出为文件，用于离线分析、长期存档或报告编制。

  1. 筛选目标日志：首先，利用上述3.1和3.2的流程，定位到需要导出的具体日志数据集。
  2. 执行导出：点击列表右上角的 「导出」 按钮。
  3. 保存文件：系统通常会生成一个CSV或Excel格式的文件，在弹出的对话框中选择本地路径保存即可。

验证方法：在指定的保存路径下找到导出的文件，用办公软件打开，确认其中的数据与网页列表显示一致。

3.4 清空历史日志

此操作用于清理过期或无用的日志数据，释放存储空间。 注意：此操作可能不可逆，请务必谨慎。

  1. 确认范围：可通过筛选日期功能，确认当前列表显示的是计划清除的日志。
  2. 执行清空：点击列表右上角的 「清空」 按钮。
  3. 二次确认：根据系统提示，确认是否清空当前筛选条件下的所有日志。

4. 常见问题与故障排除

问题现象可能原因排查与解决步骤
认证日志频繁出现“退出登录”且详情为“地址池耗尽”VPN服务（如OpenVPN）配置的IP地址池数量不足，当并发连接数超过地址池容量时，新用户无法获取IP，导致已连接用户被挤占或异常退出。1. 确认现象：在【认证】日志中筛选“事件”为退出登录，查看“日志详情”确认是否为“地址池耗尽”。 2. 解决方案：登录VPN服务配置页面，扩大IP地址池的范围（如从192.168.33.100-150改为192.168.33.100-200）。
ARP日志告警“检测到一个ARP地址欺骗”局域网内有设备发起ARP欺骗攻击，伪装成网关或其他合法设备的IP地址，意图进行中间人攻击或流量劫持。1. 定位攻击源：在【ARP】日志中查看告警详情，记录伪装的IP地址和源MAC地址（如192.168.9.100 08：9b：4b：15：e2：36）。 2. 现场排查：根据MAC地址在网络中定位对应的物理设备，检查其中毒或恶意软件情况。 3. 临时防御：在交换机或安全设备上，对受害IP或该MAC地址进行静态ARP绑定。
无线终端日志显示某设备信号强度持续偏弱（如低于-70dBm）1. 终端距离无线接入点（AP）过远或有墙体等障碍物阻隔。 2. AP发射功率设置过低或存在信道干扰。 3. 终端无线网卡驱动或硬件故障。1. 分析日志：在【无线终端】日志中筛选该设备的MAC，观察其连接的AP、信号强度和历史“事件类型”。 2. 优化位置：建议用户靠近AP，或调整AP的安装位置。 3. 检查AP配置：登录AP管理界面，检查发射功率是否合理，并优化无线信道以避免干扰。
在日志中无法搜索到预期的设备或用户记录1. 搜索关键词输入有误（如大小写、空格）。 2. 该设备或用户的活动时间不在当前筛选的日期范围内。 3. 该类型的日志未被记录（如某些静默断开可能不产生日志）。1. 检查关键词：确认搜索的MAC地址、IP或用户名完全正确。 2. 扩大时间范围：将“筛选日期”调整为更广的范围（如“本周”或“全部”）。 3. 核对日志类型：确认操作行为是否确实会生成日志。例如， DHCP租约到期导致的断开可能不会在无线终端日志中产生“退出”事件。
