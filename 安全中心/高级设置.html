高级设置使用说明

1 概述

高级设置是 iKuai OS V4 安全中心中的底层安全与连接优化功能页面，主要用于对设备的基础网络防护能力、连接行为控制能力以及 TCP 传输参数进行统一配置。管理员可通过该页面对常见的网络探测、异常连接访问、内网攻击行为和并发连接资源进行管控，并根据实际网络环境对 TCP 报文长度进行优化调整。

该页面的核心作用主要包括：

  • 边界探测防护：可控制是否允许内网或外网通过 PING、路由追踪等方式探测设备状态与网络路径；
  • 异常连接防护：可丢弃无效连接请求，并启用内网 DOS 攻击防御能力，提升设备基础安全性；
  • 连接资源控制：可限制单个 IP 的最大访问并发数，避免异常终端长期占用大量会话资源；
  • 传输参数优化：可启用 TCP 最大报文长度控制，并自定义 TCP-MSS 值，以适配 PPPoE、VPN 或特殊链路环境；
  • 统一维护入口：所有参数集中在同一页面中维护，支持直接保存生效或恢复默认配置，便于日常运维管理。

2 参数解释与操作导航

2.1 界面布局

依次点击【安全中心】>【高级设置】，进入高级设置页面。页面采用单页参数配置布局，管理员可直接在当前页面完成安全开关、连接控制和 TCP 参数设置，并通过页面顶部按钮统一保存或恢复默认配置。

参数解释表

参数名称详细说明
禁止内网PING路由用于控制内网终端是否可以通过 PING 探测设备内网地址。开启后，内网终端将无法直接 Ping 通设备。
禁止外网PING路由用于控制外网侧是否可以通过 PING 探测设备公网地址。开启后，可降低公网暴露风险。
禁止客户端tracert路由追踪用于禁止客户端通过 tracert 或 traceroute 方式追踪当前设备及其路径信息，减少网络拓扑暴露。
劫持所有PING值（游戏的Ping值为0，使用该功能时请勿禁Ping）用于对 PING 响应结果进行统一处理。常用于对延迟显示敏感的场景，启用时应避免与禁 Ping 功能同时使用。
丢弃无效的连接访问路由用于自动丢弃不符合连接状态或协议规则的异常访问请求，减少非法连接对系统资源的占用。
启用内网DOS攻击防御用于检测并拦截来自内网侧的 DOS 攻击行为，降低异常流量对设备和终端的影响。
限制每个IP允许最大访问并发数*用于设置单个 IP 地址允许建立的最大并发连接数，防止单终端过度占用会话资源。
启用TCP最大报文长度用于开启 TCP 最大报文长度控制功能，启用后可进一步设置 TCP-MSS 参数。
设置TCP-MSS值*用于设置 TCP 报文的最大分段长度，常用于 PPPoE、VPN 或特殊链路环境下的兼容性和性能优化。
注：带*号的参数项为必填项。

功能按钮说明

  • 保存：用于保存当前页面中的全部参数配置，并使配置生效；
  • 恢复默认：用于将当前页面参数恢复为系统默认值，执行前应确认当前配置已完成备份。

3 核心运维与操作流程

高级设置页面通常用于基础安全能力启停、连接资源优化及底层传输参数调整。为避免对在线业务产生影响，建议在调整前先明确需求，并在变更后及时进行验证。

3.1 配置前检查流程

  1. 明确当前调整目标，例如提升基础安全性、优化游戏场景访问体验、限制异常终端连接数或修复特定链路的传输异常。
  2. 检查设备当前运行环境，确认是否存在公网暴露、内网攻击、高并发访问或 PPPoE/VPN 传输等实际需求。
  3. 如需进行大范围调整，建议先备份现有配置，避免误操作后无法快速回退。

3.2 标准配置流程

  1. 登录设备管理页面，进入【安全中心】>【高级设置】。
  2. 根据实际需求调整相关参数：
  • 如需降低被探测风险，可启用“禁止内网PING路由”“禁止外网PING路由”或“禁止客户端tracert路由追踪”；
  • 如需增强基础安全能力，可启用“丢弃无效的连接访问路由”和“启用内网DOS攻击防御”；
  • 如需限制单个终端过度占用连接资源，可设置“限制每个IP允许最大访问并发数”；
  • 如需优化特定链路传输，可启用“启用TCP最大报文长度”，并设置合适的“TCP-MSS值”。
  1. 参数确认无误后，点击【保存】使配置生效。
  2. 如发现当前配置明显异常，且无法快速定位具体参数，可在确认已备份配置后使用【恢复默认】进行回退。

3.3 配置验证流程

  1. 调整 PING 或路由追踪相关参数后，可分别从内网侧或外网侧执行测试，确认禁止探测配置是否按预期生效。
  2. 调整 DOS 防御或无效连接丢弃能力后，应观察系统运行状态及日志变化，确认未对正常业务造成明显影响。
  3. 调整单 IP 并发限制后，应结合在线终端使用情况，确认是否存在正常业务连接被过早限制的情况。
  4. 调整 TCP-MSS 相关参数后，应对目标业务进行实际访问测试，确认链路兼容性和连接稳定性是否改善。

3.4 日常维护建议

  1. 对公网暴露环境，建议定期检查 PING 与追踪相关开关状态，避免设备长期处于可探测状态。
  2. 对终端数量较多或业务较复杂的环境，建议定期复核单 IP 并发限制值，防止设置过低影响正常办公。
  3. 对启用了 TCP-MSS 调整的环境，建议在链路、运营商或拨号方式发生变化后重新评估参数是否仍然适用。
  4. 对所有重大调整，建议记录变更时间、调整项和调整原因，便于后续排障与回溯。

4 常见问题与故障排除

问题现象可能原因排查步骤与解决方案
内网或外网仍可 Ping 通设备对应禁 Ping 开关未开启；配置修改后未保存生效；测试目标地址不正确检查“禁止内网PING路由”或“禁止外网PING路由”是否已启用；确认已点击保存；重新核对测试地址后再验证。
启用劫持所有PING值后，部分应用延迟显示异常劫持功能与禁 Ping 功能同时启用；当前业务场景不适合使用该功能检查是否同时启用了禁 Ping 项；如为游戏等延迟敏感场景，建议按实际需求调整，仅保留必要功能。
启用 DOS 防御或无效连接丢弃后，个别业务访问异常当前业务流量特征与防护策略冲突；存在误拦截情况先定位异常业务类型，再逐项检查防护项配置；必要时临时关闭相关功能验证是否由该配置引起。
设置单 IP 并发数后，部分终端访问变慢或连接失败并发连接数设置过低；目标终端本身存在高连接业务结合终端实际使用场景重新评估并发数阈值；对高连接业务终端适当提高限制值后再次验证。
调整 TCP-MSS 后，部分网站或业务访问异常TCP-MSS 值设置不合理；当前链路环境不适合该参数暂时关闭“启用TCP最大报文长度”进行对比测试；如确认与 MSS 配置有关，可重新设置更合适的数值后再验证。
恢复默认后，原有安全策略失效页面参数已被重置，之前的自定义配置未恢复如已备份配置，应优先按备份恢复；如无备份，则需重新检查并逐项恢复必要的安全与优化参数。
