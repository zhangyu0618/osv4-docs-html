其他控制使用说明

1 概述

其他控制是 iKuai OS V4 安全中心中的网络分享控制功能,主要用于限制终端通过二级路由扩展网络、设置网络分享相关的 TTL 参数、配置例外地址范围,并结合 IP 分组与时间周期对规则进行精细化控制。管理员可通过该页面统一管理网络分享控制策略,从而减少私接路由、共享热点或异常扩展网络带来的管理风险。

其他控制页面当前主要围绕 网络分享控制 展开,页面支持设置禁止二级路由、自定义 TTL、例外地址范围、IP 分组及禁止时间等内容,适合在办公网络、校园网络、宿舍网络以及需要限制网络再次分享的场景中使用。

其核心作用主要包括:

  • 禁止二级路由:用于限制终端私接二级路由或再次扩展网络;
  • 自定义TTL控制:用于设置 TTL 值,辅助控制网络分享识别与管理策略;
  • 例外地址范围配置:用于为指定地址设置豁免范围,避免关键设备被误限制;
  • 按分组生效:支持结合 IP 分组控制规则作用范围;
  • 按时间周期生效:支持结合按周循环和时间段设置规则的生效时间;
  • 集中配置维护:通过单页面完成保存、批量添加和例外地址维护操作,便于日常统一管理。

2 参数解释与操作导航

2.1 界面布局

依次点击【安全中心】>【其他控制】,进入其他控制页面。页面当前为单页配置布局,主要用于维护网络分享控制相关参数。管理员可在当前页面直接设置禁止二级路由、自定义 TTL、例外地址范围、IP 分组及禁止时间,并通过页面底部保存配置。

2.2 网络分享控制

网络分享控制功能用于对终端网络分享行为进行限制，适合控制私接路由、共享网络及特定终端的网络扩展行为。网络分享控制主页面用于展示并配置当前网络分享控制参数，支持直接维护禁止二级路由、自定义 TTL、例外地址范围、IP 分组和禁止时间等内容。

参数解释表

参数名称详细说明
禁止二级路由用于控制是否限制终端私接二级路由或继续扩展网络。开启后，终端的二级分享行为将受到限制。

周期用于在按周循环模式下选择规则生效的星期。

3 核心运维与操作流程

其他控制的日常运维通常包括需求确认、参数配置、例外地址维护、效果验证和周期调整等环节。由于该页面配置会直接影响终端网络分享行为,建议管理员在修改前先确认目标终端范围和豁免对象,再执行保存。

3.1 配置创建与调整流程

  1. 进入【安全中心】>【其他控制】页面。
  2. 根据实际需求决定是否开启"禁止二级路由"。
  3. 在"自定义TTL"中输入合适的 TTL 值。
  4. 根据需要在"例外地址范围"中通过【添加】或【批量】录入豁免地址。
  5. 如需限定作用对象,可在"IP分组"中选择目标分组。
  6. 在"禁止时间"中设置规则的时间计划、时间段及周期。
  7. 点击【保存】,使当前配置生效。

3.2 例外地址维护流程

  1. 当需要逐条增加豁免地址时,可使用【添加】逐项录入。
  2. 当需要一次性导入多个豁免地址时,可点击【批量】并按一行一条的方式输入地址。
  3. 输入完成后点击【确定】,将多条地址写入例外地址范围。
  4. 维护完成后返回主页面检查例外地址是否显示正确。

3.3 配置验证与调整流程

  1. 保存配置后,使用目标终端验证网络分享行为是否已按预期受到限制。
  2. 若关键设备受到影响,应优先检查是否已正确加入例外地址范围。
  3. 若规则未按预期生效,应检查 TTL 值、IP 分组和禁止时间配置是否正确。
  4. 当规则仅需在特定时段生效时,建议重点核对"时间计划""时间段"和"周期"设置是否匹配当前时间。

3.4 使用建议

  1. 建议在启用"禁止二级路由"前先整理好例外地址范围,避免关键设备被误限制。
  2. 对于终端较多的场景,建议优先结合 IP 分组使用,减少重复维护工作。
  3. 对于需要长期放行的设备,建议使用明确的例外地址策略而不是频繁关闭整体控制。
  4. 建议在调整 TTL 或时间策略后进行实际终端测试,再正式投入使用。

4 常见问题与故障排除

问题现象可能原因排查步骤与解决方案

批量添加地址失败或无效地址格式不符合要求;输入内容未按一行一条录入按页面要求使用 192.168.1.1 或 192.168.1.0/24 格式;确保每行只填写一条地址范围后重新提交。
