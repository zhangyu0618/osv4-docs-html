MAC访问控制使用说明

1.1 核心能力

本功能模块提供以下核心能力：

  • 黑白名单双模式：提供灵活的全局策略。黑名单模式默认允许所有设备接入，仅阻止列表中的指定MAC地址；白名单模式默认阻止所有设备接入，仅允许列表中的指定MAC地址，满足从宽松到严格的不同安全等级需求。
  • 基于时间的精细控制：每条规则均可独立设置生效的“周期”，支持按周循环和自定义时间段，实现如“仅在工作时间允许特定设备接入”或“在非营业时间禁止所有设备”等场景化策略。
  • 高效的终端标识与管理：支持为规则添加“终端名称”和“备注”，将难以记忆的MAC地址转化为易于识别的设备标识，极大提升策略的可读性和运维效率。
  • 批量运维支持：提供“批量添加”、“导入/导出”功能，便于对大量终端设备（如企业员工电脑、商场公共Wi-Fi终端）进行快速的策略部署与统一管理。

1.2 适用场景

  • 企业网络准入控制：使用白名单模式，仅允许登记在册的员工设备接入公司内网，有效防止未经授权的设备接入，保护商业机密。
  • 公共区域网络管理：在咖啡馆、图书馆等场所，可使用黑名单模式，将进行恶意扫描或占用过多带宽的设备MAC加入黑名单，禁止其再次接入，保障大多数用户的网络体验。
  • 访客网络隔离与管控：为访客网络单独启用MAC访问控制，结合时间策略，限制其访问权限和在线时长。
  • 满足合规性要求：协助满足网络安全等级保护等合规要求中关于网络接入控制和终端识别管理的相关条款。

2 参数解释与操作导航

2.1 界面布局

依次点击【安全中心】>【MAC访问控制】，进入MAC访问控制页面。

MAC访问控制页面采用功能分区布局，主要区域包括【规则列表区】、【操作功能区】、【全局设置区】等。

2.2 MAC访问控制规则列表

MAC访问控制规则列表为MAC访问规则的管理控制台，以表格形式展示所有已配置的MAC访问控制规则，支持通过搜索框快速筛选规则；提供“添加”、“批量添加”、“导入”、“导出”功能实现规则的增、批量增、导入导出；对单条规则可执行“编辑”、“停用”、“删除”，底部支持批量选择规则执行“停用”、“删除”，满足精细化、批量化的MAC访问管控需求。

  • 添加：打开"添加MAC访问控制规则"配置界面，创建单条新规则；
  • 批量添加：打开"批量添加MAC地址"窗口，批量导入MAC地址（需后续完善规则参数）；
  • 导入：从外部文件（如CSV）批量导入MAC访问控制规则；
  • 导出：将当前规则列表导出为外部文件（用于备份或跨设备迁移）；
  • 编辑（列表操作列）：修改对应MAC访问控制规则的参数（如MAC地址、周期、终端名称、备注）；
  • 停用（列表操作列）：临时禁用单条规则，规则不再拦截/允许对应MAC地址；
  • 删除（列表操作列）：永久删除单条规则，释放规则配额；
  • 批量停用（底部）：选中多条规则后，点击批量停用，同时禁用所选规则；
  • 批量删除（底部）：选中多条规则后，点击批量删除，同时移除所选规则。

点击【添加】按钮，打开添加MAC访问控制规则配置窗口。该窗口为新建MAC访问控制规则的界面，可填写规则名称、终端名称、MAC地址、生效时间（时间计划/时间段）、备注等核心参数，配置完成后将实现对特定MAC地址的访问权限控制。

批量添加MAC地址功能用于快速导入多个MAC地址，生成MAC访问控制规则草稿（需返回列表页完善名称、周期、终端名称等参数）。支持在文本框内每行输入一个MAC地址，点击“确定”后批量创建规则（状态为"未编辑"），点击“取消”则放弃本次导入。

功能按钮

  • 取消：关闭窗口，放弃本次批量添加操作；
  • 确定：验证MAC地址格式后，批量生成MAC访问控制规则（需返回列表页补充名称、周期等参数）。

2.5 MAC访问控制模式选择

MAC访问控制模式选择用于配置MAC访问控制的全局策略逻辑，决定规则的整体作用方式。提供“黑名单模式”和“白名单模式”两种全局策略：

  • 黑名单模式：默认允许所有MAC访问，仅阻止规则列表中的MAC；
  • 白名单模式：默认阻止所有MAC访问，仅允许规则列表中的MAC（规则全部停用时，放行所有MAC）。

支持“保存”配置或“取消”放弃修改。

MAC访问控制模式选择窗口如下图所示：

MAC访问控制模式选择窗口

功能按钮

  • 保存：将当前选择的全局策略（黑名单/白名单模式）保存并生效；
  • 取消：放弃当前全局策略修改，返回“MAC访问控制规则列表”页面。

2.6 规则优先级说明

当同时配置黑名单和白名单规则时，系统按照以下优先级处理：

  1. 白名单优先级更高：白名单中的MAC不受黑名单限制，即如果某个MAC地址同时出现在白名单和黑名单中，系统优先允许其访问。
  2. 时间周期生效：规则的生效时间以配置的"周期"参数为准，不在生效时间范围内的规则不生效。
  3. 状态优先：已停用的规则不参与访问控制决策。

批量操作建议：批量添加MAC后，需返回列表页为每条规则补充“名称”“周期”“终端名称”等参数，否则规则可能无法生效或难以管理。

3. 核心运维与操作流程

3.1 配置前准备

在配置MAC访问控制前，需明确管控目标，并收集必要信息，以确保策略有效且避免误拦截合法业务。

  • 信息收集与策略规划：
  • 明确管控目标：是希望禁止少数设备（黑名单），还是仅允许已知设备（白名单）。
  • 收集MAC地址：通过DHCP租约列表、交换机MAC地址表或直接在客户端设备上查看，准确记录需要管控的终端MAC地址。
  • 规划时间策略：确定每条规则是否需要仅在特定时间生效。
  • 参数规划表：建议填写以下表格，作为配置蓝图。
配置项规划值说明与注意事项
全局模式黑名单模式根据场景选择。初期建议使用黑名单模式，避免误阻断。
规则名称禁止-违规设备A清晰标识规则用途，便于管理。
MAC地址00:1A:2B:3C:00:01必须与设备真实MAC地址完全一致，格式正确。
终端名称张三的笔记本电脑（可选）便于识别的设备别名。
周期周一至周五 09:00-18:00定义规则生效的日期和时间段。
备注该设备曾进行网络扫描，临时禁止接入（可选）记录规则原因，便于审计。

3.2 标准配置操作步骤

  1. 访问页面：登录设备管理界面 → 进入【安全中心】 → 点击【MAC访问控制】。
  2. 选择全局模式（关键第一步）：
  • 点击页面上方的【设置】（或类似按钮）。
  • 在弹出的窗口中，根据规划选择 “使用黑名单模式” 或 “使用白名单模式”。
  • 点击【保存】。此设置是后续所有规则生效的基础。
  1. 添加访问控制规则：
  • 在规则列表页，点击【添加】。
  • 在弹出窗口中，填写 名称、MAC地址（必填）。
  • （可选）填写终端名称。
  • 配置生效时间：选择“时间计划”并设置具体的“时间段”和“周期”（星期）。
  • （可选）填写备注。
  • 点击【保存】。规则将出现在列表中并默认生效。
  1. 批量添加规则（如需要）：
  • 对于需要批量添加大量MAC地址（如员工设备清单）的场景，点击【批量添加】。
  • 在文本框中，严格按照 “每行一个MAC地址” 的格式输入。
  • 点击【确定】。系统会为每个MAC创建一条规则，但这些规则的名称、周期等参数为默认值或空，需要返回列表页逐一编辑补充完整，否则可能难以管理或生效时间不符合预期。
  1. 验证规则状态：确保列表中重要规则的“状态”为正常（非停用）。

3.3 配置验证与日常维护

  • 验证方法：
  • 黑名单测试：将一台测试设备的MAC加入黑名单并保存规则后，该设备应无法获取IP地址或无法访问网络资源。
  • 白名单测试：启用白名单模式后，未在列表中的设备应无法接入网络；列表中的设备应可以正常接入。
  • 时间策略测试：为规则设置一个临近的生效时间段，观察规则是否在设定时间自动生效和失效。
  • 日常维护：
  • 定期审计列表：每月或每季度审查MAC访问控制列表，及时删除已离职员工或报废设备的规则，添加新设备的规则。
  • 备份与同步：在进行批量修改前，使用【导出】功能备份规则列表。当设备更换网卡导致MAC地址变更时，必须及时更新规则。
  • 日志监控：结合系统日志，关注MAC访问控制拦截记录，分析是否存在异常接入尝试。
  • 模式评估：随着网络环境变化，定期评估当前使用的“黑名单”或“白名单”模式是否仍然符合安全与管理需求。

4. 常见问题与故障排除

问题现象可能原因排查步骤与解决方案
MAC访问控制规则已添加，但设备未被阻止/允许1. 全局模式未设置或设置错误（如想禁止设备却使用了白名单模式）。 2. 规则被停用（状态为“停用”）。 3. 规则生效时间未包含当前时间。 4. MAC地址输入错误（格式、大小写或地址错误）。1. 检查全局模式：点击【设置】，确认当前是“黑名单模式”还是“白名单模式”，并理解其含义。 2. 检查规则状态：在列表页确认规则未被“停用”。 3. 检查生效时间：确认规则的“周期”包含当前日期和时间。 4. 核对MAC地址：仔细比对规则中的MAC地址与设备真实的MAC地址是否完全一致。
启用白名单模式后，所有设备（包括列表中的）都无法上网1. 白名单规则被批量停用或未生效。 2. 规则中包含了错误的MAC地址。 3. 设备使用了随机MAC地址（如手机、新版Windows的Wi-Fi隐私功能）。1. 检查规则状态：确保白名单中的规则均为“启用”状态。 2. 验证关键设备：选取一台确定合法的设备，检查其MAC是否准确存在于一条“已启用”的规则中。 3. 关闭设备随机MAC：告知用户或在接入策略中要求关闭终端设备的“私有Wi-Fi地址”或“随机硬件地址”功能。
批量添加MAC地址后，规则管理混乱通过“批量添加”功能导入的MAC地址，系统会生成名称类似随机字符串（如AGt2pM）的规则，且周期、备注等参数为空或默认。完善规则信息：批量添加后，必须返回规则列表页，对生成的多条规则进行【编辑】，补充有意义的“名称”、“终端名称”，并配置正确的“周期”。
设备更换网卡后，原有规则失效MAC访问控制基于物理地址，网卡更换后MAC地址改变，原有规则不再匹配新设备。更新规则：获取新网卡的MAC地址，在规则列表中找到旧规则进行【编辑】，修改MAC地址；或删除旧规则，为新MAC地址创建新规则。
批量操作（停用/删除）失败1. 网络延迟或会话超时。 2. 同时选中的规则数量过多。1. 刷新页面重试。 2. 分批操作：减少单次勾选和操作的规则数量。
