行为记录使用说明

1 概述

行为记录是 iKuai OS V4 安全中心中的终端行为审计与查询功能，主要用于记录并查看终端的网址浏览记录、IM 通讯记录以及终端上下线记录，帮助管理员快速追踪网络使用行为、定位异常终端活动并辅助开展日常审计管理。

行为记录页面当前主要由 网址浏览记录、IM记录 和 终端上下线记录 三个功能标签组成，并提供 免记录设置、筛选日期、导出 和 全部清空 等通用操作。管理员可结合时间范围和搜索条件查看不同终端的网络使用行为，适合在办公网络审计、异常行为排查、终端使用分析和历史记录归档等场景中使用。

其核心作用主要包括：

  • 网址浏览记录查询：查看终端访问网址的时间、来源终端、IP 地址和应用分类等信息；
  • IM行为记录查询：查看终端使用 IM 工具时的账号、操作类型、IP 地址和时间等信息；
  • 终端上下线记录查询：查看终端上线、下线及对应在线时长和流量统计情况；
  • 按时间范围筛选：支持过去1小时、过去1天、过去7天、过去30天及自定义日期筛选；
  • 免记录控制：支持为特定对象配置免记录策略，减少不需要记录的行为数据；
  • 集中运维维护：支持搜索、导出、全部清空等统一维护操作。

2 参数解释与操作导航

2.1 界面布局

依次点击【安全中心】>【行为记录】，进入行为记录页面。页面采用多标签页布局，主要包括【网址浏览记录】、【IM记录】和【终端上下线记录】三个功能标签。页面上方提供【免记录设置】、【筛选日期】、【导出】和【全部清空】等操作按钮，管理员可在不同标签中分别查看对应类型的行为记录。

2.2 网址浏览记录

网址浏览记录功能用于按终端维度查看网站访问行为，适合分析终端访问时间、访问目标及访问类型等信息。网址浏览记录列表页用于展示当前已记录的网址访问行为，支持按时间范围筛选、搜索记录并导出结果。

  • 筛选日期：用于按时间范围筛选当前网址浏览记录；
  • 导出：用于导出当前网址浏览记录；
  • 全部清空：用于清空当前网址浏览记录。 |

3 核心运维与操作流程

行为记录的日常运维通常包括查询范围设定、行为记录查看、数据导出和记录清理等环节。为便于分析特定时间段内的终端行为，建议管理员先确定查询时间范围，再切换至对应标签页查看目标记录。

3.1 行为查询流程

  1. 进入【安全中心】>【行为记录】页面。
  2. 在【网址浏览记录】、【IM记录】或【终端上下线记录】标签中选择需要查看的行为类型。
  3. 如需限定查询周期，可点击【筛选日期】设置时间范围。
  4. 使用搜索框输入关键字，缩小记录范围并定位目标终端或行为内容。
  5. 查看列表中的行为字段，确认目标记录是否符合排查需求。

3.2 免记录维护流程

  1. 点击【免记录设置】进入配置页面。
  2. 根据需要通过【添加】或【批量】录入免记录对象。
  3. 如需调整已有对象，可使用【编辑】进行修改。
  4. 配置完成后点击【保存】，使设置生效。
  5. 返回记录列表页面，继续验证记录是否按预期采集。

3.3 数据导出与清理流程

  1. 在筛选出目标记录后，点击【导出】保存当前查询结果。
  2. 对需要长期保留的记录，建议定期执行导出备份。
  3. 在确认历史记录无需保留后，可使用【全部清空】清除当前记录数据。
  4. 在执行清空操作前，建议优先确认是否已完成必要备份。

3.4 使用建议

  1. 建议先设置时间范围，再进行搜索与分析，以提高排查效率。
  2. 对于需要长期排查的终端，可结合三个标签页交叉查看其浏览、IM 和上下线行为。
  3. 对于不需要纳入审计的对象，建议通过免记录设置统一管理，避免反复手工清理。
  4. 如页面显示“暂无内容”，应优先检查当前筛选周期内是否存在有效记录。

4 常见问题与故障排除

问题现象可能原因排查步骤与解决方案
页面显示“暂无内容”当前查询时间段内无行为记录；系统尚未采集到对应数据检查当前筛选日期范围；尝试切换到更长的查询周期；确认系统中已有实际终端行为发生。
搜索后未找到目标记录关键字不准确；查询时间范围过窄；目标对象已被设置为免记录重新确认搜索关键字；扩大时间范围重新查询；检查免记录设置中是否已排除目标对象。
IM记录或网址浏览记录缺失目标对象被加入免记录设置；当前查询范围不正确检查免记录设置；核对筛选日期是否覆盖目标行为发生时间。
导出结果为空或与预期不符导出前页面当前无数据；筛选条件未设置正确导出前先确认列表已有目标记录；核对筛选日期和搜索条件后重新导出。
清空后无法恢复历史记录已执行全部清空且未提前导出备份建议在执行“全部清空”前先完成导出；如已清空，只能等待系统重新累积新记录。
