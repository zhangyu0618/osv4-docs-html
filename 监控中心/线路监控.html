线路监控使用说明书

1 概述

线路监控是 OSv4 网络设备管理系统的核心功能模块，专注于对设备各网络接口的实时状态、流量性能及连接质量进行全方位监控与分析。该功能通过图形化面板、监控列表和状态检测信息相结合的方式，为网络管理员提供直观的线路状态仪表盘，是保障网络稳定运行、进行容量规划与故障快速定位的重要工具。

线路监控页面主要由图形监控窗口、线路监控列表、线路状态检测页签和 IPv6 线路详情页签构成，并提供自动刷新、清空流量统计、详情等操作入口，可用于同时查看 IPv4/IPv6 线路流量、线路接入状态和链路质量指标。

1.1 主要功能特性

  • 图形化线路面板:以接口图标方式直观展示 WAN、LAN、ETH、VNET 等接口状态及速率类型。
  • 实时流量监控:查看每条线路的上行速率、下行速率、累计上行和累计下行数据。
  • 丢包质量分析:支持查看今日上行丢包率和今日下行丢包率，用于快速判断链路质量。
  • 线路状态检测:查看 IP 地址、网关、接入模式、连接时间和线路检测状态，辅助定位拨号或获取地址失败问题。
  • IPv6 线路分析:独立查看 IPv6 线路连接数、实时速率与累计流量，适用于双栈网络运维。
  • 详情趋势分析:通过"详情"按钮进入对应线路的历史趋势视图，便于分析波动、拥塞或异常时段。

2.1 访问路径

在管理界面左侧导航菜单中，依次点击 【监控中心】 > 【线路监控】，即可进入线路监控主页面，如下图所示：

线路监控页面

2.2 界面布局与参数说明

线路监控页面主要分为以下几个部分:

  1. 图形监控窗口
  2. 线路监控列表
  3. 线路状态检测页签
  4. IPv6 线路详情页签

其中，页面上方提供 新建接口 按钮;监控列表区域提供 自动刷新、清空流量统计 等操作入口。

2.2.1 图形监控窗口

此区域采用图标化设计，如同设备的"物理面板"，实时反映每个物理接口的连接与工作状态。可见接口类型包括 WAN1、WAN2、LAN1、LAN2、ETH2、VNET 等，同时界面下方展示速率/状态图例，如 100M、1G、2.5G、10G、离线、空接口、POE、供电中、聚合、异常。

图形监控窗口

参数解释表

参数名称详细说明
接口标识显示接口名称(如 WAN1、LAN1、ETH2、VNET)，对应设备上的物理端口或逻辑接口。
速率标签表示该接口当前的通讯速率类型，如 100M、1G、2.5G、10G。
离线表示接口处于非工作状态或链路未建立。
空接口表示当前接口未接入网线或未建立物理连接。
POE表示该接口具备以太网供电能力。
供电中表示该接口当前正在为下联设备供电。
聚合表示该接口属于链路聚合组成员。
异常表示接口已建立连接但存在异常状态，需进一步检查。

功能按钮说明

  • 新建接口:点击窗口上方的【新建接口】，会跳转至【网络设置】>【内外网设置】页面。

2.2.2 线路监控列表

这是页面默认展示的核心数据区，以表格形式展示各线路的实时运行指标。表头包含:线路、IP 地址、连接数、上行速率、下行速率、累计上行、累计下行、今日上行丢包率、今日下行丢包率、备注、操作。

页面中可见的线路既包括 wan1、wan2 等外网线路，也包括 lan1、lan2、vlan10、vlan100、vlan200 等内网或 VLAN 线路，因此该页面不仅用于观察外网链路，也可用于查看内部逻辑线路的基础流量情况。

线路监控数据列表

  • 自动刷新:用于自动更新当前监控列表数据，便于实时查看线路变化。
  • 清空流量统计:点击后可将当前累计流量统计归零，适用于重新开始一个新的统计周期。
  • 详情:点击后进入该线路的流量历史趋势图，用于深度性能分析。

2.2.3 线路状态检测页

页面上方提供 线路状态检测 页签，用于查看线路接入层配置与连通性状态。该区域更偏向"线路是否接通、是否正常获取地址、是否成功拨号、链路检测是否通过"等状态信息。

线路状态检测列表

参数解释表

参数名称详细说明

IP 地址线路当前获取到的 IPv4 地址。若显示 --，通常表示未完成地址获取。

3 核心运维与操作流程

3.1 日常巡检:快速掌握线路总体状态

目标:快速判断关键 WAN/LAN/VLAN 线路是否在线、是否存在明显丢包或异常流量波动。

操作流程:

  1. 查看图形监控窗口:确认 WAN、LAN、VNET 等关键接口是否处于正常连接状态。
  2. 查看线路监控列表:重点关注 wan1、wan2 等出口线路的 IP 地址、实时速率和丢包率。
  3. 查看丢包情况:同时检查"今日上行丢包率"和"今日下行丢包率"，确认是否持续为 0%。
  4. 查看备注和用途:结合"备注"字段识别业务线路、测试线路或隔离用途线路。
  5. 必要时切换页签:如需确认链路检测结果或 IPv6 情况，再切换到"线路状态检测"或"IPv6 线路详情"页签继续查看。

3.2 深度排查:分析特定线路访问缓慢问题

场景:用户反馈访问外网缓慢，怀疑某条 WAN 出口存在问题。

操作流程:

  1. 定位出口线路:在"线路监控"列表中查看各 WAN 线路的实时上/下行速率。
  2. 检查双向丢包率:重点查看"今日上行丢包率"和"今日下行丢包率"是否异常升高。
  3. 检查 IP 获取状态:如 wan2 的 IP 地址为 --，需优先判断其是否根本未接通。
  4. 进入详情视图:点击对应线路的【详情】按钮，查看历史趋势图，分析问题是持续性还是突发性。
  5. 结合状态检测页签:如需确认拨号或地址获取问题，切换至"线路状态检测"页签查看"接入模式"和"线路检测状态"。

3.3 流量统计与清空

目标:统计周期流量并在需要时重置累计值。

操作流程:

  1. 查看累计流量:通过"累计上行"和"累计下行"字段观察某条线路在当前统计周期内的流量消耗情况。
  2. 筛选重点线路:优先关注 WAN 出口线路和高业务量 VLAN 线路。
  3. 清空统计:点击【清空流量统计】后，将所有线路的累计流量归零，开始新的统计周期。
  4. 重新观察:清空后继续结合自动刷新功能，监测新的流量增长情况。

3.4 排查"IP 地址未获取"问题

目标:定位 WAN 线路未获取地址、拨号失败或 DHCP 异常的原因。

操作流程:

  1. 先看线路监控列表:若某条 WAN 的"IP 地址"为 --，说明当前未成功获取地址。
  2. 切到线路状态检测页签:进一步查看"接入模式""连接时间"和"线路检测状态"。
  3. 按接入模式排查:
  • 若为 PPPoE:重点检查账号密码是否正确、运营商线路是否正常。
  • 若为 DHCP:重点检查上级 DHCP 服务器是否可达、物理链路是否正常。
  1. 看检测状态结果:
  • 若为"拨号失败":优先检查拨号配置或联系运营商。
  • 若为"DHCP 获取失败":检查上级设备和地址分配情况。
  • 若为"异常":进一步结合接口状态、丢包率和链路质量分析问题。

3.5 分析 IPv6 流量分布

目标:独立分析 IPv6 线路使用情况和业务特征。

操作流程:

  1. 切换至 IPv6 线路详情页签。
  2. 查看连接数:判断当前 IPv6 会话是否活跃。
  3. 对比上下行速率:分析业务是否以下行流量为主或上传流量为主。
  4. 查看累计流量:识别是否存在长时间高占用的 IPv6 业务。
  5. 结合 IPv4 结果综合判断:若 IPv4 正常但 IPv6 异常，可进一步定位为双栈中 IPv6 独立问题。

4 常见问题与故障排除指南

现象可能原因排查步骤
接口显示"离线"或"空接口"1. 网线未接入。2. 对端设备断电。3. 端口被禁用。4. 接口存在物理层异常。1. 检查网线连接和指示灯状态。2. 确认对端设备供电和工作状态。3. 检查接口配置是否启用。4. 如仍异常，尝试更换端口或网线。
WAN 口 IP 地址为"--"1. PPPoE 拨号失败。2. DHCP 未分配地址。3. 运营商链路异常。4. 接入方式配置错误。1. 切换到"线路状态检测"页签查看接入模式和检测状态。2. 检查 PPPoE 账号密码或 DHCP 上级设备。3. 联系运营商确认外线状态。4. 检查 WAN 接口配置是否正确。
某线路今日上/下行丢包率持续偏高1. 线路带宽持续满载。2. 链路质量差。3. 上级设备异常。4. 设备正遭遇异常流量冲击。1. 查看实时速率和详情趋势图，判断是否为持续拥塞。2. 检查物理链路质量。3. 对比其他线路是否正常。4. 结合连接数和异常流量继续定位。
累计流量异常激增1. 某业务或终端持续上传/下载数据。2. 内网存在异常同步、备份或视频流。3. 策略配置不当导致异常转发。1. 先在本页面确认是哪条线路增长最快。2. 结合终端监控或行为洞察定位流量来源。3. 必要时通过策略或限速方式控制异常对象。
IPv6 线路有流量但 IPv4 正常、用户仍异常1. IPv6 业务本身异常。2. 双栈下仅 IPv6 路由或解析异常。3. IPv6 流量被错误策略影响。1. 切换到"IPv6 线路详情"页签查看连接数和速率。2. 对比 IPv4 和 IPv6 是否表现一致。3. 检查 IPv6 路由、DNS 和策略配置。
