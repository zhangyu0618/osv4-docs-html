认证账号管理使用说明

1 概述

认证账号管理是网络运营与用户接入控制的核心枢纽，为网络服务提供商（如企业、校园、酒店、运营商）提供了一套完整的用户账号生命周期管理方案。它不仅支持基础的账号与密码管理，还覆盖套餐定义、账号开通、自助服务、上网码分发及财务流水记录等多个环节，可满足认证接入场景中的统一管理需求。

其核心价值主要体现在以下几个方面：

  • 实现服务产品化与标准化：通过套餐管理，将网络资源（如带宽、时长）打包为可复用的标准服务项，便于面向不同用户群体提供差异化接入服务；
  • 支持多种账号创建与认证方式：既可直接创建固定账号，也可通过上网码方式提供临时接入服务；
  • 提升自助服务能力：支持不同认证类型用户自行修改密码或退出登录，减轻管理员的日常维护压力；
  • 保障运营记录清晰可追溯：通过总账管理记录开户、续费等收费流水，便于财务核对和运营分析；
  • 提高批量运维效率：支持账号、套餐、上网码的导入、导出、批量启停和删除，适合大规模用户管理场景。

该模块主要由【套餐管理】、【账号管理】、【自助密码管理】、【总账管理】和【上网码管理】等部分组成。管理员通常先在套餐管理中定义服务套餐，再在账号管理或上网码管理中为用户开通认证接入权限，并通过总账管理和自助服务功能完成后续运营维护。

2 参数解释与操作导航

2.1 界面布局

依次点击【认证服务】>【认证账号管理】，进入认证账号管理页面。

认证账号管理页面采用多标签页布局，主要包括【套餐管理】、【账号管理】、【自助密码管理】、【上网码管理】、【代拨服务管理】和【总账管理】等功能页签，用于实现认证账号从创建、分配、使用到维护的完整管理流程。

2.2 套餐管理

套餐管理用于统一配置和维护可分配给认证账号的上网套餐。管理员可在此对套餐进行新增、编辑、导入、导出和删除，并查看套餐的名称、带宽、时长、价格和备注等信息。

套餐管理页面如下图所示：

套餐管理主页面

功能按钮说明

  • 搜索框：输入套餐名称或备注关键词，快速筛选目标套餐；
  • 添加：打开添加套餐窗口，创建新的上网套餐；
  • 导入：批量导入套餐配置，适用于初始化或统一更新场景；
  • 导出：导出当前套餐列表，便于备份或离线分析；

  • 删除：删除目标套餐。执行前应确认没有账号正在使用该套餐。

3 核心运维与操作流程

3.1 套餐规划与配置流程

  1. 根据目标用户群体和接入需求，规划套餐的价格、带宽、有效期和适用说明；
  2. 进入【套餐管理】页面，点击【添加】；
  3. 填写套餐名称、周期类型、有效期、价格和带宽等参数；
  4. 保存后，套餐即可用于后续账号分配。

3.2 账号开通与分发流程

  • 方式一：直接创建账号
  1. 进入【账号管理】页面，点击【添加】；
  2. 填写账号、密码、认证类型、套餐及网络参数；
  3. 按需填写用户姓名、联系电话等客户信息；
  4. 保存后，账号即可投入使用。
  • 方式二：通过上网码分发
  1. 进入【上网码管理】页面；
  2. 选择【添加】创建单个上网码，或选择【批量生成】创建多个上网码；
  3. 配置有效期、限时和备注等参数；
  4. 将生成的上网码分发给用户，由用户在认证页面完成接入。

3.3 日常账号维护流程

  1. 在【账号管理】页面使用状态筛选和搜索框定位目标账号；
  2. 按需执行编辑、停用、缴费或删除等操作；
  3. 如需同时处理多个账号，可通过批量操作统一启用、停用或删除；
  4. 在【自助密码管理】页面按需启用相关用户类型的自助服务功能。

3.4 财务对账与数据维护流程

  1. 进入【总账管理】查看所有收费记录；
  2. 使用【筛选日期】查询指定时间范围内的财务流水；
  3. 通过【导出】功能导出对账数据；
  4. 定期检查上网码与套餐使用情况，并清理失效数据。

4 常见问题与故障排除

问题现象可能原因排查步骤与解决方案
用户账号无法认证上网账号被停用、已过期、未关联有效套餐，或认证类型不匹配。在【账号管理】中检查账号状态、到期时间、关联套餐和认证类型设置。
上网码输入后提示无效或失效上网码已过期、已被使用、限时耗尽，或已被删除。在【上网码管理】中检查该上网码的状态、过期时间和使用记录，必要时重新生成新的上网码。
用户无法通过自助页面修改密码自助密码管理总开关或对应用户类型开关未启用，或用户访问条件不满足。检查【自助密码管理】配置，并确认用户在已认证状态下访问自助页面。
批量导入账号或上网码失败导入文件格式不正确、必填项缺失、数据格式错误，或存在重复记录。使用系统导出模板准备数据，并检查格式、内容完整性和唯一性。
总账管理记录与实际收款不符收费金额录入错误、线下收款未在系统中记录，或历史记录被误删。核对收费金额和描述字段，并确保所有收费行为均通过系统操作留痕。
账号突然断开并提示在线设备超限账号共享数设置过低，已达到允许同时在线的终端数量上限。编辑账号配置，适当增加共享数，或提醒用户退出其他设备登录。
