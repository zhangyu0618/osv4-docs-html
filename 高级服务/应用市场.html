应用市场使用说明

应用市场使用说明

1. 概述

应用市场位于【高级服务】模块下，是 iKuai OS V4 提供的应用资源浏览、应用部署入口和应用运行入口统一管理页面。该页面用于集中展示系统支持的应用资源，并提供查看教程、快速安装、启动和本地安装等操作入口。

应用市场采用"子版块切换 + 应用卡片展示"的组织方式。页面上方提供【全部】、【已安装】、【更新】等入口，页面主体区域以应用卡片形式展示应用的名称、版本、分类、安装包大小及页面展示数值，并提供对应的操作按钮。

应用市场支持展示多类应用资源，包括开发工具、媒体云盘、实用工具、远程访问、网络加速和网络测速等类别。该页面适用于应用浏览、应用部署、应用启动和应用维护等场景。

总体而言，应用市场不是复杂的参数配置页面，而是面向应用展示、快速部署和运行入口管理的统一工作页面。通过该页面，可完成应用浏览、安装和运行入口访问等常见操作。

2. 参数解释与操作导航

2.1 界面布局

依次点击【高级服务】>【应用市场】，进入应用市场页面。

应用市场页面采用统一入口式布局。页面顶部用于切换不同视图，页面主体区域用于展示应用卡片。每个应用卡片均可展示应用的基本信息和对应操作。

2.2 全部

应用市场"全部"页面是展示平台内所有可安装应用的聚合界面，支持通过搜索、分类筛选、排序等方式快速查找目标应用，提供应用详情查看、快速安装等功能，帮助用户便捷获取并部署所需应用。

"全部"页面如下图所示：

应用市场-全部

功能按钮

  • 本地安装：点击后打开本地文件选择界面，支持从本地设备导入应用安装包进行安装（适用于无网络或需安装离线包的场景）；
  • 搜索框：在输入框中输入关键词（如应用名称、分类等），列表将实时过滤显示包含该关键词的应用，提升查找效率；
  • 筛选下拉菜单：点击后展开分类筛选菜单，可选择"下载工具"、"网络加速"、"实用工具"等类别，仅展示对应类别的应用；
  • 排序下拉菜单：点击后展开排序选项菜单，可选择"下载量"、"好评量"、"发布时间（降序）"等排序方式，按需求调整应用列表的展示顺序；
  • 查看教程（应用卡片按钮）：针对单条应用，点击后跳转至该应用的专属教程页面，提供安装、配置、使用等详细指引；
  • 快速安装（应用卡片按钮）：针对单条应用，点击后启动应用的安装流程，自动完成下载、安装及初始化（如需）操作，快速部署应用。

2.3 快速安装

应用市场"快速安装"模块为用户提供一键式应用部署服务，支持快速安装预封装的应用，并在安装前自定义资源限制（CPU、内存、端口）与应用启动状态，简化从"选择应用"到"部署运行"的全流程，降低应用部署门槛。

应用市场-快速安装

功能按钮说明

  • 取消：点击后终止当前快速安装流程，关闭安装配置界面，回到应用市场或上一级页面；
  • 安装：点击后根据当前配置（资源限制、启动状态等），自动下载并安装"Ubuntu 开发工具"，完成应用部署；
  • 恢复默认值：点击后将"CPU限制"、"内存限制"、"Ubuntu SSH端口"等配置参数重置为系统默认值，便于快速恢复初始配置；
  • 安装说明（标签页）：切换至该标签页可查看应用的安装要求、依赖项、注意事项等说明文档，辅助安装前准备。

2.4 本地安装

【本地安装】用于通过本地资源包导入方式安装应用。该功能适用于离线部署、本地测试和手动导入应用等场景，是应用市场对在线安装方式的补充。

本地安装页面如下图所示：

应用市场-本地安装

安装步骤

步骤1：准备安装包

确保本地设备中存在 .ipkg 格式 的安装包（若格式不符，需先转换或重新获取合规包）。

步骤2：上传安装包（二选一）

  • 方式1：点击选择

点击"点击选择安装包或把安装包拖拽至此区域"的文本区域，在弹出的文件选择窗口中，找到并选中本地的 .ipkg 安装包，点击「打开」完成上传。

  • 方式2：拖拽上传

直接将本地 .ipkg 安装包文件，从电脑文件夹中拖拽到该文本区域内，系统会自动识别并上传。

步骤3：确认安装

上传完成后，点击右下角的 「确定」 按钮，系统将开始安装流程（安装过程中请保持网络稳定、勿关闭页面，避免安装失败）。

步骤4：取消操作（可选）

若上传过程中需放弃安装，点击右下角的 「取消」 按钮，可终止当前上传/安装流程，回到初始状态。

注意事项

  • 仅支持 .ipkg 格式 的安装包，其他格式（如 .deb、.exe 等）无法通过此功能安装。
  • 安装包大小可能影响上传速度，建议在网络稳定的环境下操作。
  • 若安装报错（如"包损坏"、"依赖缺失"等），需检查安装包完整性或补充依赖后再尝试。

通过以上步骤，即可完成本地 .ipkg 安装包的上传与安装。

2.5 已安装

应用市场"已安装"页面是展示设备中已成功安装的所有应用的聚合管理界面，支持通过搜索、分类筛选快速定位应用，提供"查看教程"（辅助应用使用）、"启动"（快捷运行应用）等功能，帮助用户高效维护和管理已部署的应用。

已安装页面如下图所示：

应用市场-已安装页面

功能按钮说明

  • 查看教程（应用卡片按钮）：针对单条应用，点击后跳转至该应用的专属教程页面，提供安装、配置、使用等详细指引（如 Ubuntu 的开发环境配置教程）；
  • 启动（应用卡片按钮）：针对单条应用，点击后直接启动已安装的应用（如启动 Lucky 远程访问工具、OpenList 媒体云盘客户端）；
  • 本地安装：点击后打开本地文件选择界面，支持从本地设备导入 .ipkg 等格式的应用安装包，补充在线安装的离线场景；
  • 搜索框：在输入框中输入关键词（如应用名称、分类），列表将实时过滤显示包含该关键词的应用，提升查找效率（如搜索"Ubuntu"快速定位开发工具）；
  • 筛选下拉菜单：点击后展开分类筛选菜单，可选择"开发工具"、"远程访问"、"媒体云盘"等类别，仅展示对应类别的已安装应用，便于批量管理同类应用。

3. 核心运维与操作流程

本章节详细说明应用市场各核心功能的标准化操作流程，指导用户完成日常运维任务。

3.1 浏览与筛选应用

此操作用于在应用市场中查找和了解可用应用。

  1. 登录设备：访问 iKuai OS V4 管理平台并登录。
  2. 进入应用市场：依次点击导航栏中的【高级服务】>【应用市场】，默认进入【全部】视图。
  3. 浏览应用列表：页面将以卡片形式展示所有可用应用，每个卡片包含应用名称、版本、分类、大小及热度数值。
  4. 精确查找：
  • 搜索：在顶部搜索框输入应用名称或关键词，可实时过滤列表。
  • 筛选：点击搜索框旁的"全部"下拉菜单，可按应用类别（如"开发工具"、"媒体云盘"）进行筛选。
  • 排序：点击"综合"下拉菜单，可选择按"下载量"、"好评量"或"发布时间"对列表进行排序。
  1. 查看应用详情：点击任意应用卡片上的【查看教程】按钮，可跳转至该应用的详细说明与配置指南页面。

验证方法：

  • 【全部】页面正常加载并显示多个应用卡片。
  • 搜索、筛选、排序功能可即时生效并改变列表显示内容。
  • 点击【查看教程】后，能正确跳转到对应的帮助页面。

3.2 管理已安装应用

此操作用于查看、启动和管理设备上已安装的应用。

  1. 切换视图：在应用市场顶部，点击【已安装】选项卡。
  2. 查看应用状态：页面将列表展示所有已成功安装的应用及其基本信息（名称、版本、分类等）。
  3. 运行应用：对于需要手动启动的应用，点击其卡片上的【启动】按钮即可运行。
  4. 寻求帮助：如需配置或使用指导，可点击对应应用卡片的【查看教程】按钮。

验证方法：

  • 【已安装】视图能正确列出当前设备中已部署的所有应用。
  • 已安装应用卡片上显示【启动】和【查看教程】按钮，且点击后能触发相应动作。

3.3 检查与应用更新

此操作用于检查和安装应用的可更新版本。

  1. 切换视图：在应用市场顶部，点击【更新】选项卡。
  2. 查看更新状态：页面将展示存在新版本的应用列表，并标明当前版本与可更新状态。
  3. 执行更新：根据页面提示，对有更新的应用执行【快速安装】（覆盖安装新版本）或类似操作。
  4. 查看更新说明：在执行更新前，可点击【查看教程】了解新版本的变更内容和注意事项。

验证方法：

  • 【更新】视图能正常打开，并准确反映应用的更新状态。
  • 更新操作可被成功触发，系统有相应的处理进度反馈。

3.4 执行本地安装（离线部署）

此操作用于通过本地安装包文件部署应用，适用于离线环境或安装特定版本。

  1. 进入本地安装界面：在应用市场顶部，点击【本地安装】选项卡或按钮。
  2. 上传安装包：
  • 方式一（点击上传）：点击上传区域的"点击选择安装包或把安装包拖拽至此区域"。
  • 方式二（拖拽上传）：直接将本地的 .ipkg 格式安装包文件拖拽至该区域。
  1. 确认安装：文件上传成功后，点击右下角的【确定】按钮，系统将开始安装流程。
  2. 取消操作（可选）：在上传或安装过程中，可随时点击【取消】按钮中止当前操作。

验证方法：

  • 能成功进入本地安装界面并选择 .ipkg 文件。
  • 文件上传后，点击【确定】能触发系统安装流程，并有进度提示。
