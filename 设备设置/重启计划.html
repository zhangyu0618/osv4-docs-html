重启计划使用说明

1 概述

重启计划是设备设置中的定时运维功能模块，用于为系统配置自动重启任务，帮助管理员在业务低峰时段按计划执行重启操作。通过合理设置重启计划，可以在不依赖人工值守的情况下，定期释放系统资源、清理运行状态，提升设备长期运行的稳定性。

重启计划模块支持按一次、每天、每周、每月四种周期策略配置自动重启任务，具备计划新增、编辑、启用/停用、删除以及立即重启/立即关闭服务器等操作能力，适用于日常维护、定期保养、异常恢复预案等多种运维场景。

2 参数解释与操作导航

2.1 界面布局

依次点击【设备设置】>【重启计划】，进入重启计划页面。

重启计划页面以列表管理方式展示当前已创建的重启任务，页面上方提供立即执行类操作按钮与新增按钮，列表区域展示各计划的名称、事件类型、执行周期、日期、时间、备注及状态信息，便于管理员统一查看与维护。

2.2 重启计划列表

重启计划列表页是重启任务的管理控制台，支持对现有计划进行查看、添加、编辑、启用/停用、删除等操作，同时可通过页面顶部按钮快速执行立即重启服务器或立即关闭服务器操作。管理员可在此页面集中维护设备的周期性重启策略。

2.2.1 重启计划主页

重启计划页面如下图所示：

重启计划主页面

功能按钮说明

  • 立即重启服务器：立即触发设备重启操作，执行后当前管理连接会中断；
  • 立即关闭服务器：立即执行设备关机操作，适用于设备停机维护场景；
  • 添加：打开“添加重启计划”配置窗口，创建新的定时重启任务；
  • 编辑（列表操作列）：修改对应重启计划的名称、周期、日期、时间及备注等参数；
  • 启用/禁用（列表操作列）：切换当前计划的生效状态，启用后计划会按设定时间自动执行；
  • 删除（列表操作列）：移除当前重启计划，删除后不可恢复；

2.2.2 添加/编辑重启计划

点击主页上的【添加】按钮，或在列表操作列点击【编辑】按钮，打开重启计划配置窗口。该窗口用于创建或修改单条重启计划，可配置计划名称、计划事件、执行周期、日期条件、执行时间及备注等参数。不同周期类型下，日期字段会自动切换显示方式，以匹配对应的时间策略。

添加重启计划窗口如下图所示：

参数解释表

参数名称详细说明
名称*自定义重启计划名称，建议使用明确反映执行场景的名称，如“每周维护重启计划”。
计划事件*计划执行的动作类型，当前页面固定为“重启”，通常无需修改。

在重启计划列表中通过复选框选中一条或多条计划后，可进入批量操作状态，对选中的计划统一执行启用、禁用或删除等管理动作，如下图所示：

重启计划批量操作界面

功能按钮说明

  • 批量启用/停用：统一切换选中计划的启用状态，便于集中维护；
  • 批量删除：统一删除选中的重启计划，执行前应确认所选计划已不再使用；
  • 取消选择：取消当前勾选状态，退出批量处理场景。

3. 核心运维与操作流程

3.1 配置前准备

在创建或调整重启计划前，建议先完成以下准备工作，以确保计划配置合理且不会影响业务连续性：

  • 确认维护窗口：优先选择业务低峰时段执行自动重启，避免影响在线用户或关键业务；
  • 梳理计划目的：明确每条计划的用途，例如每日释放资源、每周维护、月度保养等；
  • 核对时间策略：确认计划应使用一次、每天、每周还是每月策略，避免误配置为错误的重复周期；
  • 评估启用时机：新建计划后建议先核对参数，再根据需要手动启用，避免配置完成即进入运行状态；
  • 记录运维说明：建议在备注中写明用途、执行窗口或责任人，方便后续识别与维护。
配置项规划建议示例值备注
计划名称使用可识别命名每日凌晨重启计划建议体现周期与用途

3.2 标准配置操作步骤

遵循以下顺序完成重启计划的新增、修改和启用操作：

  1. 访问页面：登录设备管理界面 → 进入【设备设置】→ 点击【重启计划】；
  2. 新增计划：点击页面右上角【添加】按钮，打开“添加重启计划”窗口；
  3. 填写基础信息：输入“名称”，确认“计划事件”为“重启”；
  4. 选择执行周期：根据实际需求选择“一次”“每天”“每周”或“每月”；
  5. 配置日期条件：
  • 若选择“每天”，日期字段通常无需额外设置；
  • 若选择“每周”，在日期字段中选择具体星期；
  • 若选择“每月”，在日期字段中选择具体日期；
  1. 设置执行时间：选择计划执行的具体时间，建议设置在网络空闲或维护时段；
  2. 填写备注：如有需要，在备注中补充说明该计划的用途；
  3. 保存计划：点击【保存】完成创建；
  4. 按需启用：返回列表页后，根据实际需要点击对应计划的【启用】按钮，使其正式生效。

3.3 配置验证与日常维护

  • 验证方法：
  • 新建或编辑完成后，返回列表页确认计划是否成功显示；
  • 检查“周期”“日期”“时间”“备注”等列内容是否与预期一致；
  • 检查状态列是否为预期状态，如需自动执行，应确认其已切换为“已启用”；
  • 对每周或每月计划，建议重点核对日期字段是否正确，避免执行日错误。
  • 日常维护：
  • 定期清理旧计划：删除不再使用或重复的历史计划，保持列表整洁；
  • 统一命名规范：建议长期使用“周期 + 场景”的命名方式，降低误操作概率；
  • 修改前先核对状态：编辑生效中的计划前，建议先确认是否会影响当前运维安排；
  • 重要操作安排在维护窗口：无论是启用计划还是立即重启服务器，均建议安排在可控时间段执行。

4. 常见问题与故障排除

问题现象可能原因排查步骤与解决方案
创建计划后未自动执行1. 计划创建成功但未启用。 2. 配置的执行时间尚未到达。 3. 周期或日期设置错误。1. 在列表页检查状态列是否为“已启用”。 2. 核对当前系统时间与计划时间是否一致。 3. 检查周期与日期字段是否匹配预期，例如每周计划是否选对星期。
每周计划执行日不正确星期选择理解错误，或保存时未正确选择具体星期。1. 编辑对应计划重新核对“周期=每周”时的日期字段。 2. 保存后返回列表页再次确认显示结果是否为目标星期。
每月计划没有按预期日期执行日期字段配置错误，或选择了不存在的执行逻辑。1. 检查“周期”是否为“每月”。 2. 检查“日期”是否为预期数字，如 1、15、28。 3. 保存后回到列表页核对显示内容。
需要临时停止计划但不想删除计划当前处于启用状态。直接在列表页点击该计划对应的【禁用】按钮，将状态切换为“未启用”，后续需要恢复时再点击【启用】。
误删计划后能否恢复删除属于不可逆操作。当前页面一般不提供回收或恢复机制，误删后需重新手动创建相同计划。建议删除前先核对名称、周期与用途。
立即重启服务器后页面断开设备执行重启时管理连接会中断，属于正常现象。1. 等待设备完成重启。 2. 重新通过管理地址登录。 3. 建议在执行前通知相关使用人员，并确认当前无关键业务运行。
批量操作未达到预期效果可能未正确勾选目标计划，或对批量操作范围理解有误。1. 重新勾选目标计划并确认选中项。 2. 执行批量启用、禁用或删除前再次核对名称。 3. 操作后刷新页面确认结果。
