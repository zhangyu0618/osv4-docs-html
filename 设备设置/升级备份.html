升级备份使用说明

1 概述

升级备份是设备设置中的系统维护模块，主要用于对设备软件版本、组件库版本以及配置快照进行统一管理。管理员可通过该模块查看当前系统版本信息、执行版本检测、本地升级、维护版本快照，并在需要时进行配置恢复或恢复出厂设置等操作。

1.1 核心能力

该模块主要包含以下核心能力：

  • 版本信息管理：查看当前路由系统版本、发布时间以及协议库、通讯工具特征库、网址库等组件版本信息；
  • 在线检测与通道管理：支持执行版本检测，并按业务需要选择正式版（推荐）、体验版（Beta）或内测版等版本通道；
  • 本地升级：支持上传本地升级文件，对系统或组件进行离线升级；
  • 版本快照管理：支持查看已有备份、下载备份、恢复备份、删除备份，以及从外部备份文件导入并恢复；
  • 恢复与重置：支持恢复默认配置，以及在必要时执行恢复出厂设置；
  • 自动备份：支持定时自动备份机制，可按日、周、月周期配置，便于在日常运行中保留可用恢复点。

1.2 功能定位说明

升级备份模块面向设备版本维护、组件更新与配置安全保障场景设计，既可用于日常版本检查和升级管理，也可用于异常回退、配置恢复和设备初始化。该模块通常适用于以下场景：

  • 新版本发布后的版本检测与升级；
  • 安全策略更新或组件库（协议库、特征库、网址库）的自动/手动升级；
  • 网络维护窗口内执行本地升级包导入；
  • 对当前稳定配置创建版本快照，作为版本回退或配置回滚的依据；
  • 设备配置异常或业务调整后的备份恢复；
  • 设备交接、回收或需要清空现有配置时执行恢复默认配置或恢复出厂设置。

2 参数解释与操作导航

2.1 页面结构

依次点击【设备设置】>【升级备份】，进入升级备份页面。

升级备份页面主要由以下两个功能模块组成：

  • 版本升级：查看当前设备版本信息，执行版本检测、本地升级、查看历史日志和了解版本通道；
  • 版本快照：查看和维护配置备份，执行恢复、下载、删除、恢复默认配置及恢复出厂设置等操作。

2.2 版本升级

版本升级页面用于展示设备当前软件版本和相关组件版本信息，并提供版本检测、本地升级及升级维护入口。管理员可通过该页面快速掌握系统版本状态，并根据升级策略选择合适的版本通道。

  • 历史日志：查看与升级相关的历史记录；
  • 隐私政策：查看升级相关的隐私政策说明。

2.2.2 本地升级

本地升级功能用于在无法直接在线更新、需要离线维护或已提前获取升级包的场景下，通过上传本地升级文件完成版本更新。支持通过点击上传或拖拽文件的方式导入升级包。

本地升级页面如下图所示：

本地升级页面

功能按钮说明

  • 点击上传：选择本地升级文件并上传；
  • 取消上传：放弃当前上传与升级操作；
  • 确定上传：确认当前所选升级文件并提交上传；
  • 访问官网下载最新版本：跳转至对应下载入口，获取可用升级文件。
注：执行本地升级前，建议先确认当前设备版本、升级包适配范围以及业务维护窗口，必要时先做好配置备份。

2.3 版本快照

版本快照页面用于对设备当前配置进行备份、恢复和清理管理。管理员可在该页面查看可用备份文件，执行下载、恢复、删除等操作，并可结合自动备份机制提升配置回退能力。

功能按钮说明

  • 还原/备份：
  • 下载外部备份：从外部存储（如U盘、FTP服务器）导入备份文件至设备，支持恢复历史配置（需确保外部备份与设备系统版本兼容）。
  • 恢复外部备份：将已导入的外部备份文件恢复至当前系统，覆盖现有配置（操作后系统参数将与备份时的状态一致）。
  • 恢复默认配置：
  • 恢复默认配置：将系统配置重置为出厂默认参数（保留基础网络参数，如IP地址可能需重新配置），适用于快速清除自定义配置。
  • 恢复出厂设置：将系统所有配置（含自定义参数）恢复为出厂状态（相当于“设备重置”），操作后需重新配置网络、用户权限等所有参数，需谨慎执行。
  • 自动备份开关：
  • 开启：启用定时自动备份，系统按预设时间（如每天09：30）生成配置备份，无需手动干预。
  • 关闭：停止自动备份功能，需手动执行“备份”操作或依赖外部备份管理配置。
  • 新建备份：点击![](./assets/升级备份_04.png)按钮，系统将生成包含当前全部配置信息（如网络、用户、业务参数等)的备份文件，可用于后续系统恢复或异地存档，备份文件会自动加入备份列表供下载、恢复等管理操作；
  • 备份列表操作列（下载/恢复/删除）：
  • 下载：将当前选中的本地备份文件下载至外部存储介质（如U盘），用于异地备份或跨设备恢复。
  • 恢复：将选中的备份文件的配置覆盖至当前系统（操作前建议先备份当前配置，避免数据丢失）。
  • 删除：永久移除选中的备份文件，释放设备存储空间（删除后无法通过该文件恢复配置）。

2.3.2 自动备份设置

在版本快照主页点击!12 自动备份设置按钮，打开自动备份设置窗口。自动备份设置用于定时生成系统配置备份文件，避免手动备份的繁琐操作，确保系统配置可按预设周期自动留存，便于故障恢复或版本回溯。

自动备份设置窗口如下图所示：

自动备份设置

参数解释表

参数名称详细说明
备份周期选择自动备份的执行频率，可选「单次」「每日」「每周」「每月」，决定备份任务的触发周期。

功能按钮说明

  • 保存：应用当前备份参数（周期、时间、保留时效），新策略立即生效；
  • 取消：放弃本次修改，关闭设置窗口，保留原有备份配置。

3 核心运维与操作流程

3.1 配置前准备

在进行升级、备份或恢复操作前，建议先完成以下准备工作：

  • 确认维护窗口：升级、恢复和恢复出厂设置可能导致业务中断，建议在非业务高峰期操作；
  • 备份关键配置：在执行升级或重置前，建议先创建并导出可用备份，确认备份文件有效；
  • 确认备份存储空间：操作前检查设备存储空间是否充足，特别是准备新建备份或本地升级时；
  • 校验升级文件：执行本地升级前确认升级文件类型（.bin/.lib/.patch）、版本兼容性和设备适配范围；
  • 确认供电稳定：升级与恢复过程中应避免断电，建议使用UPS等不间断电源；
  • 评估回退方案：操作前确认至少存在一份有效备份作为回退路径，发生异常后可及时恢复。

3.2 版本检测与通道调整流程

  1. 进入【设备设置】→【升级备份】→【版本升级】；
  2. 查看当前系统版本及组件库版本信息；
  3. 根据需要选择对应的版本通道（正式版/体验版/内测版）；
  4. 点击【版本检测】检查是否存在可更新内容；
  5. 根据检测结果安排后续操作：
  • 检测到更新：根据业务需要选择在线升级或获取升级包后执行本地升级；
  • 未检测到更新：确认版本通道设置是否正确，或等待新版本发布后再次检测；
  1. 更新完成后返回版本升级页面，核对系统版本号和组件库版本号是否已更新。

3.3 本地升级流程

  1. 进入【设备设置】→【升级备份】→【版本升级】；
  2. 点击【本地升级】，打开本地升级窗口；
  3. 通过点击上传或拖拽方式导入升级文件（支持 .bin、.lib、.patch 等格式）；
  4. 确认所选文件符合格式要求，且版本适配当前设备；
  5. 点击【确定上传】提交升级包，等待系统处理；
  6. 观察升级处理状态：
  • 上传中：等待文件上传完成；
  • 校验中：系统自动校验升级文件完整性和兼容性；
  • 升级中：系统正在执行版本更新，严禁断电或强制重启；
  1. 升级完成后返回版本升级页面，重新核对系统版本号与组件库版本号；
  2. 如有需要，可点击【历史日志】查看升级操作记录，确认升级结果。

3.4 备份恢复流程

3.4.1 现有备份恢复

  1. 进入【设备设置】→【升级备份】→【版本快照】；
  2. 查看当前可用备份列表，确认目标备份的名称、版本和备份时间；
  3. 恢复操作前，建议先新建备份保存当前配置，避免恢复后无法回退；
  4. 选择目标备份，点击【恢复】操作按钮；
  5. 阅读弹窗提示，确认恢复操作的影响范围；
  6. 点击【确认】执行恢复，等待系统完成；
  7. 恢复完成后检查业务配置是否正常：
  • 核对网络配置、用户权限、业务策略等关键参数；
  • 验证设备是否按预期运行；
  1. 如需导出备份至外部，选择目标备份后点击【下载】。

3.4.2 外部备份恢复

  1. 进入【设备设置】→【升级备份】→【版本快照】；
  2. 点击【下载外部备份】从外部存储介质（U盘、FTP等）导入备份文件；
  3. 确认外部备份与当前设备系统版本兼容；
  4. 选中已导入的备份文件，点击【恢复外部备份】；
  5. 确认恢复操作，覆盖当前系统配置；
  6. 恢复完成后检查业务配置是否恢复正常。

3.5 恢复默认配置或出厂设置流程

  1. 进入【设备设置】→【升级备份】→【版本快照】；
  2. 先确认当前配置是否已备份，若尚未备份，建议先【新建备份】并【下载】保存至外部存储；
  3. 点击【恢复默认配置】；
  4. 根据需要选择恢复默认配置或继续进入恢复出厂设置：
  • 恢复默认配置：将系统配置重置为出厂默认参数（保留基础网络参数），适用于快速清除自定义配置；
  • 恢复出厂设置：将系统所有配置（含自定义参数）恢复为出厂状态，操作后需重新配置所有参数；
  1. 仔细阅读页面提示，确认以下影响：
  • 业务中断影响；
  • 网络连接将丢失；
  • 设备将自动重启；
  1. 确认无误后点击【确认】执行恢复操作；
  2. 等待设备重启完成（切勿手动断电），通过默认或预设方式重新登录；
  3. 按初始化要求重新配置网络参数、用户权限和业务策略；
  4. 如有备份文件，可通过【版本快照】→【恢复】导入备份快速恢复配置。

4 常见问题与故障排除

常见问题可能原因排查建议
版本检测后未发现可升级内容当前版本已是最新、所选版本通道不匹配或检测范围受限检查当前版本通道设置，尝试切换至其他通道后重新检测，确认是否存在对应通道的可用升级包。
本地升级文件无法上传文件格式不符合要求、文件损坏或文件内容与设备不匹配确认上传文件是否为 .bin、.lib、.patch 等支持格式，并从官方渠道重新获取正确升级包。
升级过程中断或失败升级过程中断电、网络中断、文件校验失败或设备过热保持供电稳定（建议使用UPS），重新执行升级操作；检查升级文件完整性，必要时重新下载；若反复失败，重新启动设备后重试。
升级后版本未变化上传内容并非目标版本包、升级未成功完成或需要重启后生效重新核对升级包版本号与目标版本是否一致，检查升级执行结果提示，确认设备是否已按要求重启。
手动创建备份失败存储空间不足、配置异常或系统资源繁忙检查设备存储空间是否充足，稍后重试备份操作；若持续失败，可尝试关闭部分非必要服务或删除过期备份后重试。
自动备份未按计划执行自动备份开关未开启、备份周期/时间配置异常或系统时间不正确检查自动备份开关是否处于开启状态，核对备份周期和时间设置，确认设备系统时间准确（建议启用NTP同步）。
备份下载后文件无法使用下载过程中文件损坏、存储介质故障或备份文件版本不兼容重新从备份列表下载备份文件，确认下载完成后检查文件大小是否正常，确保目标设备系统版本与备份兼容。
备份恢复后配置不符合预期恢复的备份版本较旧或所选备份文件不正确核对备份名称、备份时间和对应版本号后重新选择正确的备份文件执行恢复；恢复前建议先备份当前配置。
恢复出厂设置后无法立即访问网络恢复操作会导致设备重启并清空原有网络配置等待设备重启完成后重新登录设备，并按初始化向导重新配置网络参数（IP地址、网关、DNS等）。
恢复过程中出现异常操作期间断电、文件异常或恢复链路中断保持供电稳定（建议使用UPS），必要时重新执行恢复操作，并优先使用在操作前创建的有效备份文件。
