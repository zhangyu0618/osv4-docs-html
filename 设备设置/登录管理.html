登录管理使用说明

1 概述

登录管理是设备设置中的统一身份与访问控制模块，用于集中管理本地登录账号、个人 API 令牌以及远程访问相关配置。通过该模块，管理员可以为不同运维人员分配独立账号、配置允许访问来源地址、细化页面访问与修改权限，并根据自动化调用或异地运维需求启用 API 令牌与远程管理能力，从而在保证管理效率的同时提升设备整体安全性。

在实际运维中，登录管理不仅承担“谁可以登录”的基础身份管理职能，还承担“从哪里登录”“登录后能做什么”“远程入口如何开放”“接口调用凭证如何发放”等关键安全控制任务。合理使用该模块，可有效降低共享管理员账号、弱口令、过度授权、远程入口暴露等常见风险。

登录管理模块主要由以下三个部分组成：

  • 账号设置：用于新增、编辑、启用、停用、复制和删除本地登录账号，并对允许访问 IP、登录超时、密码安全策略及页面级权限进行精细化控制；
  • 个人 API 令牌：用于为脚本调用、系统集成、接口联调等场景生成独立访问凭证，避免直接暴露账号密码；
  • 远程访问：用于配置 Web 管理入口协议、访问端口、外网访问控制、自定义 SSL 证书以及远程维护能力，满足异地管理与安全接入需求。

从页面结构上看，登录管理采用标签式布局，管理员可在同一功能入口下完成账号、令牌和远程访问三类配置，适合统一实施最小权限控制、访问边界管理和运维审计策略。

2 参数解释与操作导航

2.1 界面布局

依次点击【设备设置】>【登录管理】，进入登录管理页面。

登录管理页面采用标签式布局，主要包括【账号设置】、【个人API令牌】、【远程访问】等功能区域。不同标签页分别对应本地账号维护、接口访问凭证管理以及远程访问能力配置。

2.2 账号设置

账号设置页面用于管理系统的登录账号，支持账号查询（顶部搜索框）、账号增删改查（添加、编辑、启用/停用、删除、复制）及权限精细化配置（密码安全、页面权限等），帮助管理员管控用户的登录权限与访问范围。

2.3 个人 API 令牌

个人 API 令牌页面用于对个人API令牌进行查询、添加、删除操作，可配置令牌的名称、有效期、权限范围及备注信息，帮助用户安全管理API访问凭证（如控制令牌有效期、限制权限范围）。

API令牌可用于第三方应用集成、自动化脚本调用、跨系统数据同步等场景，通过令牌代替账号密码实现安全API访问，避免直接暴露账号凭证。

2.4.1 远程访问主页面

远程访问页面如下图所示：

远程访问主页面

参数解释表

参数类参数名称详细说明
访问控制Telnet服务端用于控制设备是否开启 Telnet 远程管理服务。开启后，可通过 Telnet 协议远程连接设备进行命令行管理。由于 Telnet 传输过程默认不加密，存在账号和命令内容被窃听的风险，除特殊维护场景外，一般不建议长期开启。

HTTPS访问端口*指定 Web 管理界面通过 HTTPS 协议访问时所使用的端口号。默认值为 443，输入范围为 1-65535。该端口承担加密管理访问入口的作用，建议结合防火墙放行策略及可信来源限制进行统一规划。
外网WEB访问控制*用于控制设备 Web 管理界面的外网访问范围。该项直接影响设备后台是否可从公网或外部网络访问，建议根据实际场景谨慎配置，避免无必要地暴露管理入口。
自定义SSL证书用于为 HTTPS Web 管理界面配置自定义 SSL 证书。可在此处导入/管理符合要求的证书文件，以提升浏览器访问可信度并满足统一证书管理要求。
远程维护开启访问路由控制台位于“远程维护”区域，用于控制是否允许远程访问路由控制台。开启后，相关技术支持或远程维护人员可通过指定方式对设备进行进一步诊断和维护。
远程维护端口*用于指定远程维护或访问路由控制台时所使用的服务端口。默认值为 22，输入范围为 10-65535。该端口决定远程维护入口对外监听的访问通道，建议根据实际安全策略使用非默认端口，并结合防火墙、来源地址限制等措施共同使用，降低被扫描和暴力尝试的风险。
远程维护密码*用于设置访问路由控制台时所需的认证密码。该密码属于远程维护场景下的重要安全凭证，建议设置为高强度密码，包含字母、数字和特殊字符，并避免与后台登录密码重复使用。若密码设置过于简单，可能导致远程维护入口存在被非法访问的风险。
技术支持报告技术支持报告导出技术支持相关报告，便于问题排查、设备状态分析或提交给官方技术支持人员进行故障诊断。
注：带*号的项为必填项。

功能按钮说明

  • 管理：进入自定义 SSL 证书管理界面，用于上传、查看或维护 HTTPS 所使用的自定义证书文件；
  • 前往绑定：跳转至爱快云绑定或相关云平台接入页面，用于将当前设备接入云端集中管理；
  • 导出技术报告：导出当前设备的技术支持报告，便于排障、留档或提交给技术支持人员分析；
  • 保存：保存当前远程访问页面中的配置项，包括访问控制、端口设置、外网访问策略和远程维护开关等内容。

2.4.2 远程访问 - 自定义 SSL 证书

当需要使用自定义 HTTPS 证书进行远程访问时，可在远程访问页面进入 SSL 证书配置区域，上传证书文件和私钥文件，以提升浏览器访问可信度并满足统一证书管理要求。

自定义 SSL 证书界面如下图所示：

远程访问 - 自定义SSL证书

参数解释表

参数名称详细说明
自定义SSL证书用于启用或关闭自定义 SSL 证书功能。开启后，设备 Web 管理界面可使用管理员手动配置的证书与私钥进行 HTTPS 加密访问，而不是仅使用系统默认证书。该功能适用于对浏览器信任链、统一证书管理或企业安全合规有要求的场景。
证书(CRT)用于填写或导入服务器证书内容，即证书正文。通常应粘贴完整的 PEM 格式证书文本，内容一般以 -----BEGIN CERTIFICATE----- 开始，以 -----END CERTIFICATE----- 结束。该证书用于向浏览器证明设备服务端身份。
私钥(KEY)用于填写或导入与服务器证书配套的私钥内容。通常应粘贴完整的 PEM 格式私钥文本，内容一般以 -----BEGIN RSA PRIVATE KEY----- 或其他兼容私钥头开始，并以对应结束标识结尾。私钥必须与证书匹配，否则 HTTPS 服务将无法正常使用。
备注用于填写该 SSL 证书的说明信息，便于后续区分证书用途、来源、适用域名或替换记录。在实际使用中，建议填写如“远程管理正式证书”、“测试环境证书”、“xx域名证书”等易识别描述。

功能按钮说明

  • 保存：保存当前自定义 SSL 证书配置，使设备使用填写的证书与私钥内容进行 HTTPS 服务加密访问。
  • 取消：放弃当前未保存的证书内容修改，关闭当前自定义 SSL 证书管理窗口。
  • 自定义SSL证书（开关）：用于开启或关闭自定义 SSL 证书功能。开启后，设备将尝试使用管理员填写的证书和私钥提供 HTTPS 访问。

3. 核心运维与操作流程

3.1 配置前准备

在进行登录管理配置前，建议先完成以下准备工作：

  • 明确账号分工与权限边界：提前规划超级管理员、只读运维、网络维护、审计查看等不同角色所需权限，避免所有人员共用高权限账号；
  • 梳理可信访问来源：统计允许登录后台的办公出口 IP、运维电脑地址或管理网段，用于填写“允许访问IP”与远程访问限制项；
  • 确认自动化与集成需求：若需要对接脚本、第三方平台或外部系统，应提前明确 API 调用范围、令牌归属人及有效期策略；
  • 规划远程访问安全策略：确认是否需要开启外网 Web 访问、是否强制 HTTPS、是否使用自定义 SSL 证书，以及是否确有必要启用远程维护；
  • 准备变更窗口与回退方案：涉及远程访问端口、SSL 证书或高权限账号调整时，建议在低峰期执行，并提前准备回退方式，避免误操作导致无法远程管理设备；
  • 检查现有配置可用性：在修改前确认当前管理员账号可正常登录，确认已有证书、令牌与远程入口状态正常，必要时先截图或备份当前配置。

3.2 标准配置操作步骤

3.2.1 新增本地登录账号

  1. 进入【设备设置】→【登录管理】→【账号设置】；
  2. 点击【添加】按钮，打开新增账号界面；
  3. 输入用户名、密码和确认密码；
  4. 填写允许访问 IP，建议仅放行可信运维终端或管理网段；
  5. 设置默认权限策略，并按需配置登录超时时间、密码安全策略和页面权限；
  6. 保存配置后返回账号列表；
  7. 检查账号状态是否正常显示，并使用该账号实际登录一次；
  8. 验证该账号仅能访问被授权页面，且来源地址限制生效。

3.2.2 批量处理账号状态

  1. 进入【设备设置】→【登录管理】→【账号设置】；
  2. 通过复选框选中需要处理的账号；
  3. 根据运维需要执行【批量启用】、【批量停用】或【批量删除】；
  4. 操作完成后逐项核对目标账号状态，避免误处理非目标账号；
  5. 对高权限账号进行批量操作前，建议保留至少一个可正常登录的管理员账号，防止全部账号被误停用。

3.2.3 创建个人 API 令牌

  1. 进入【设备设置】→【登录管理】→【个人API令牌】；
  2. 点击【添加】按钮，打开新增令牌界面；
  3. 填写令牌名称，并根据需要设置过期时间或“永久有效”；
  4. 选择令牌权限范围，优先使用满足业务所需的最小权限；
  5. 按需填写备注，标明用途、归属系统或对接脚本；
  6. 保存配置后记录令牌信息，并交付给对应脚本或系统使用；
  7. 使用接口调试工具或目标系统进行联调，确认认证与权限均正常生效。

3.2.4 配置远程访问入口

  1. 进入【设备设置】→【登录管理】→【远程访问】；
  2. 根据安全要求决定是否开启 Telnet服务端，一般建议保持关闭或仅临时开启；
  3. 建议开启 强制https WEB访问，提升管理流量加密安全性；
  4. 设置 HTTP 与 HTTPS 访问端口，并确认上级防火墙、NAT 或安全策略已同步放行；
  5. 配置 外网WEB访问控制，根据实际运维场景限制可从外部访问的地址类型或范围；
  6. 保存配置后，从允许的访问网络测试管理页面能否正常打开。

3.2.5 配置自定义 SSL 证书

  1. 在【远程访问】页面点击 管理，进入【自定义SSL证书】界面；
  2. 开启 自定义SSL证书 开关；
  3. 在【证书(CRT)】中填写或粘贴完整证书正文；
  4. 在【私钥(KEY)】中填写与证书匹配的完整私钥内容；
  5. 在【备注】中填写证书用途说明，如“远程管理正式证书”；
  6. 点击【保存】提交配置；
  7. 使用浏览器重新访问 HTTPS 管理地址，检查证书是否生效、是否过期、浏览器是否仍存在告警。

3.2.6 启用远程维护

  1. 在【远程访问】页面勾选 开启访问路由控制台；
  2. 填写 远程维护端口 与 远程维护密码；
  3. 确认当前操作为可信维护或官方支持场景，避免在不明来源要求下开启；
  4. 保存配置后，将远程维护信息仅提供给可信技术支持人员；
  5. 维护完成后，建议及时关闭远程维护入口或修改远程维护密码，减少长期暴露风险。

3.3 配置验证与日常维护

3.3.1 配置完成后的验证建议

  • 账号验证：使用新建账号实际登录，检查用户名、密码、账号状态、允许访问 IP 及页面权限是否按预期生效；
  • 权限验证：分别测试“访问”与“修改”权限，确认账号只能查看或操作被授权模块，避免出现权限过大或功能缺失；
  • 令牌验证：通过脚本、Postman 或目标系统调用接口，验证 API 令牌的认证结果、权限范围与有效期是否正确；
  • 远程入口验证：从允许的外部地址访问 Web 管理入口，确认 HTTP/HTTPS 端口、外网访问控制和页面跳转行为符合预期；
  • 证书验证：通过浏览器查看 HTTPS 证书详情，确认域名、有效期、签发信息和证书链状态正常；
  • 远程维护验证：仅在确需远程协助时测试路由控制台访问能力，并确认远程维护端口和密码已设置成功。

3.3.2 日常维护建议

  • 定期停用或删除长期不用的本地账号，避免遗留账户长期可用；
  • 定期轮换高权限账号密码，并按需启用周期修改密码策略；
  • 定期检查 API 令牌清单，及时清理测试令牌、失效令牌和不再使用的集成凭证；
  • 定期复核“允许访问IP”与“外网WEB访问控制”设置，避免在人员、办公地点或网络环境变化后保留无效放行规则；
  • 对公网开放的 HTTPS 管理入口，定期检查证书有效期并提前续期或更换；
  • 远程维护功能仅在必要时短时开启，维护完成后及时关闭或更新密码；
  • 建议在重要配置变更后保留操作记录，包括账号变更、证书替换、端口调整和令牌发放情况，便于追踪和审计。

4. 常见问题与故障排除

问题现象可能原因排查步骤与解决方案
新建账号后无法登录1. 用户名或密码输入错误；2. 账号处于停用状态；3. 当前登录来源 IP 不在允许范围内；4. 登录超时或会话异常。1. 重新核对用户名、密码和确认密码是否填写正确；2. 在账号列表中确认账号是否已启用；3. 检查当前运维终端 IP 是否命中“允许访问IP”；4. 如为旧会话问题，退出后重新登录测试。
账号能登录，但页面或菜单不完整1. 页面权限未授权；2. 默认权限策略不足；3. 账号仅具备访问权限、无修改权限。1. 检查该账号在“页面权限”中的授权范围；2. 确认相关模块是否同时授予“访问”和“修改”；3. 如为新功能菜单，检查“默认权限”策略是否允许读写。
账号无法从外部网络登录后台1. 外网WEB访问控制限制；2. 上级防火墙/NAT 未放行；3. HTTP/HTTPS 端口填写错误；4. 强制 HTTPS 后仍使用 HTTP 访问。1. 检查“外网WEB访问控制”设置；2. 核对外部访问使用的端口与设备页面端口配置是否一致；3. 检查出口防火墙、路由映射或安全策略；4. 若开启了强制 HTTPS，请改用 https:// 方式访问。
HTTPS 页面提示证书不可信或证书错误1. 使用默认自签名证书；2. 自定义证书与私钥不匹配；3. 证书已过期；4. 证书内容格式不完整。1. 检查是否已启用自定义 SSL 证书；2. 核对证书(CRT)与私钥(KEY)是否配套；3. 检查证书有效期与签发信息；4. 确认粘贴内容包含完整的 BEGIN/END 标识。
保存自定义 SSL 证书后 HTTPS 无法正常访问1. 证书内容或私钥内容录入错误；2. 证书格式不符合要求；3. 证书并非当前管理地址可用证书。1. 重新核对证书与私钥是否完整；2. 确认页面要求的证书类型与格式；3. 使用原有管理入口或本地网络方式回退配置；4. 必要时恢复为默认配置后重新导入。
API 令牌调用失败或接口返回无权限1. 令牌已过期或已删除；2. 令牌权限不足；3. 使用了错误的令牌；4. 对接脚本仍在使用旧令牌。1. 在个人API令牌列表中确认令牌状态；2. 检查令牌是否配置为所需权限范围；3. 核对调用方实际使用的令牌值；4. 对变更后的令牌重新完成接口联调。
远程维护无法连接或协助失败1. 未开启访问路由控制台；2. 远程维护端口未开放；3. 远程维护密码错误；4. 相关网络路径被拦截。1. 确认“开启访问路由控制台”已勾选；2. 检查远程维护端口配置与上级放行策略；3. 重新核对远程维护密码；4. 如为公网访问，检查链路中的安全设备、NAT 和访问控制策略。
批量停用或删除后出现误操作1. 选中范围错误；2. 未先核对目标账号；3. 对高权限账号执行了误处理。1. 返回账号列表逐项核查处理结果；2. 优先保留至少一个可登录的管理员账号；3. 若误停用，可使用仍可登录的管理员账号重新启用；4. 后续执行批量操作前先按用户名或用途筛选确认。
