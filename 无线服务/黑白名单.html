黑白名单使用说明

1 概述

黑白名单是无线服务中基于终端MAC地址的接入控制功能，通过黑名单模式（禁止指定终端接入指定SSID）和白名单模式（仅允许指定终端接入指定SSID），实现终端级别的无线准入管理，可有效拦截非法设备、保障高安全场景的接入合规性。

该模块支持多维度规则限定（SSID、AP、生效周期）、单条/批量/分组MAC录入，以及规则的导入、导出、启用/停用、编辑、删除等运维操作，适配企业办公、访客网络、高安全隔离等场景，主要功能包括：

  • 黑名单控制：禁止规则中的终端MAC连接指定SSID，用于拦截异常、非法或不受欢迎的无线终端；
  • 白名单控制：仅允许规则中的终端MAC连接指定SSID，适用于高安全性、强管控的无线接入场景；
  • 多维度生效范围限制：可结合SSID、AP和周期对规则生效范围进行限定，减少误拦截或误放行；
  • 多终端统一纳管：支持单条MAC录入、批量录入及分组方式，便于集中管理多台终端；
  • 规则运维管理：支持规则的添加、导入、导出、编辑、启用/停用、删除等日常维护操作。

2 参数解释与操作导航

2.1 界面布局

依次点击【无线服务】>【黑白名单】，进入黑白名单页面。

黑白名单页面主要包含规则列表区、功能按钮区、规则配置区和批量操作区。管理员可在列表页查看已有规则，也可通过“添加”按钮进入新增页面，创建黑名单或白名单控制策略。

2.2 黑白名单主页

黑白名单主页为黑白名单规则的管理控制台，支持对现有规则进行添加、导入、导出、编辑、启用/停用、删除等操作；页面以列表形式展示规则的名称、控制模式、终端MAC地址、SSID、AP、周期、备注等核心信息，便于管理员快速了解当前无线准入控制策略的部署情况。

参数解释表

参数名称详细说明
名称黑白名单规则名称，用于区分不同无线接入控制策略，建议采用具备业务含义的命名方式。
控制模式当前规则的工作模式，可为黑名单模式或白名单模式。黑名单模式用于禁止接入，白名单模式用于仅允许规则内终端接入。

AP当前规则生效的AP范围，可用于将控制策略限定在指定AP上。
周期当前规则的生效日期与时间范围，用于控制规则在指定时间段内生效。
备注对当前规则用途、适用终端、部署背景或维护说明的补充描述。
操作提供编辑、启用/停用、删除等维护入口。

功能按钮

  • 添加：打开“添加黑白名单”配置页面，用于创建新的黑名单或白名单规则；
  • 导入：导入本地黑白名单配置文件，便于批量恢复或迁移既有规则；
  • 导出：导出当前黑白名单规则，便于备份、归档或跨设备复用；
  • 编辑（列表操作列）：打开对应规则的编辑界面，修改名称、控制模式、终端MAC、SSID、AP、周期及备注等参数；
  • 停用 / 启用（列表操作列）：控制该规则是否参与实际无线接入控制，停用后规则暂不生效；
  • 删除（列表操作列）：移除当前黑白名单规则，删除前建议确认无终端业务依赖。

2.3 添加/编辑黑白名单配置

点击主页上的【添加】按钮，打开添加黑白名单配置页面。该页面用于新建黑名单或白名单规则，可填写规则名称、控制模式、终端MAC地址、SSID、AP、生效周期及备注等核心参数。配置完成后，系统将根据规则内容决定终端是否允许连接目标无线网络。

周期指定规则生效的日期范围，如周一至周日，可用于按周控制策略执行时段。
生效时间*指定规则生效的起止时间，为必填项，用于控制规则在每天的具体时间段内生效。
备注对规则背景、适用终端、部署原因等进行补充说明，便于后续管理与排障。
注：带*为必填项，格式要求需严格遵循，否则可能导致配置无法保存或策略不生效。

功能按钮

  • 批量：批量录入多个终端MAC地址，适用于多台终端同时纳入同一控制规则；
  • 添加：新增一条MAC地址输入项，用于逐条补充终端MAC；
  • 保存：保存当前黑白名单规则并写入系统；
  • 取消：放弃当前配置并返回上一页面。

2.4 批量操作

黑白名单批量操作页面主要用于对已勾选的黑白名单规则进行统一维护，适合在规则数量较多时进行集中启用、停用或删除操作。通过批量操作功能，管理员可减少重复点击，提高日常运维效率。

批量操作页面如下图所示：

黑白名单批量操作页面

功能按钮

  • 批量启用：对已勾选的黑白名单规则统一执行启用操作，使这些规则重新参与无线准入控制；
  • 批量停用：对已勾选的黑白名单规则统一执行停用操作，使这些规则暂时不再生效；
  • 批量删除：对已勾选的黑白名单规则统一执行删除操作，适用于清理无效或不再使用的规则。
注：批量操作适用于多条规则同时维护，执行前建议先确认勾选对象无误。

3. 核心运维与操作流程

3.1 添加黑白名单规则

  1. 进入页面：登录AC管理后台，依次点击【无线服务】→【黑白名单】。
  2. 点击添加：在黑白名单列表页点击 「添加」 按钮，弹出添加规则窗口（见IMG_02）。
  3. 配置规则参数：
  • 名称：自定义规则名称（如List_Test-1），便于识别。
  • 控制模式：选择 黑名单模式 或 白名单模式。
  • 终端MAC地址：
  • 可直接输入单条MAC（如06：7F：8E：9D：AC：BD）。
  • 可通过 「MAC设置」 批量添加多条MAC（如0A：C1：D2：E3：F4：05等）。
  • 可使用 「分组」 功能引用已预定义的MAC分组（如MAC test），分组内的所有MAC将统一应用规则。
  • SSID：选择规则生效的SSID（如Test-1）。
  • AP：选择规则生效的AP设备（如08：9b：4b：15：e2：36(IK-Q3000)），支持指定具体AP或“全部AP”。
  • 周期：
  • 勾选 周期 可设置生效的星期范围（如一二三四五六日）和每日生效时间（如00：00-23：59）。
  • 若不勾选，则规则永久生效。
  • 备注：可填写规则用途或说明信息（如“禁止访客区域蹭网”）。
  1. 保存：点击 「确定」 完成规则添加，规则将立即生效（需确保AC已同步至AP）。

3.2 编辑黑白名单规则

  1. 在黑白名单列表页找到目标规则，点击操作列的 「编辑」。
  2. 修改规则参数（名称、MAC地址、SSID、AP、周期等），点击 「确定」 保存。

3.3 启用/停用黑白名单规则

  • 单条操作：在操作列点击 「启用」（规则状态为“停用”）或 「停用」（规则状态为“启用”）。
  • 批量操作：勾选多个规则，点击列表底部的 「启用」 或 「停用」 按钮。

3.4 删除黑白名单规则

  • 单条删除：点击操作列的 「删除」，确认后规则被移除。
  • 批量删除：勾选多个规则，点击 「删除」 按钮。

3.5 导入/导出黑白名单规则

  • 导出：点击列表页的 「导出」 按钮，将当前所有规则（含名称、控制模式、MAC、SSID、AP、周期等）导出为CSV文件，用于备份或离线编辑。
  • 导入：点击 「导入」 按钮，选择提前准备好的CSV文件（格式与导出模板一致），批量添加规则。导入前请确保文件格式正确（MAC地址分隔符、SSID名称等），避免导入失败。

3.6 查看规则生效状态

在黑白名单列表页，每条规则的状态列（由操作列中的“启用”或“停用”图标体现）可直观查看规则是否生效。若规则处于“停用”状态，则无线终端不受该规则限制；若处于“启用”状态，则终端接入时将匹配规则并执行对应控制动作。

4. 常见问题与故障排除

问题现象可能原因排查与解决步骤
添加规则后，终端仍能连接/无法连接1. 规则未启用。 2. 规则中的SSID、AP与实际接入不匹配。 3. AP未同步最新配置。 4. 终端MAC地址被其他规则或其他模块覆盖（如MAC过滤）。1. 检查规则是否处于“启用”状态。 2. 核对规则中的SSID、AP是否与实际终端连接的网络一致（如终端连接的是2.4G SSID，但规则绑定的是5G SSID）。 3. 在AC上手动触发AP配置同步，或等待2-3分钟自动同步。 4. 检查【无线服务】→【MAC过滤】或其他接入控制模块是否存在冲突规则。
导入规则失败1. CSV文件格式不符（列名、分隔符、MAC格式错误）。 2. 文件中存在重复MAC或SSID不存在。 3. 文件编码非UTF-8。1. 先导出一个示例文件作为模板，按照模板格式编辑。 2. 确保文件中MAC地址使用英文冒号分隔（如00：11：22：33：44：55），SSID名称与AC上配置的完全一致。 3. 将文件另存为UTF-8编码（Windows记事本保存时选择UTF-8）。
白名单模式下，已允许的终端仍无法连接1. 终端MAC输入错误（大小写、空格、分隔符）。 2. 白名单规则生效周期未覆盖当前时间。 3. 终端连接了其他未配置白名单的SSID。1. 核对终端真实MAC地址（可从终端无线详情或AC日志中获取）。 2. 检查规则的生效时间（星期和时段）是否包含当前时间。 3. 确认终端连接的是规则绑定的SSID。
黑名单规则未生效，异常终端仍可连接1. 黑名单规则被其他具有更高优先级的白名单规则覆盖。 2. 黑名单规则中的AP未指定正确（如规则绑定AP-A，但终端连接的是AP-B）。 3. 终端MAC地址伪造（MAC欺骗）。1. 检查AC上是否同时存在该终端的白名单规则（白名单优先级高于黑名单时，白名单会覆盖黑名单）。 2. 确认黑名单规则的AP范围是否包含终端实际连接的AP，建议规则中AP选择“全部AP”。 3. 对于MAC欺骗，需结合无线IDS或端口安全等高级功能进行防护。
规则列表页显示异常（如MAC地址乱码、SSID为空）1. 规则配置时输入了非法字符。 2. 系统版本升级后兼容性问题。1. 编辑规则，重新输入正确的MAC地址或SSID名称。 2. 刷新页面或清理浏览器缓存；若问题持续，建议重启AC服务。
